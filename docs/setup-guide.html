ถ้าหาไอคอนไม่เจอ ให้กดในกล่องโค้ดแล้วกด Ctrl+A ตามด้วย Ctrl+C ก็ได้เหมือนกัน

กลับมาที่แท็บ Apps Script แล้วทำ 3 อย่างนี้ตามลำดับ:

  1. คลิกลงไปในช่องโค้ด (ที่มีคำว่า function myFunction())
  2. กด Ctrl+A (Mac: ⌘+A) เพื่อเลือกทั้งหมด แล้วกด Delete ให้ว่างเปล่า
  3. กด Ctrl+V (Mac: ⌘+V) เพื่อวางโค้ดที่คัดลอกมา
⏳
โค้ดยาว 4,199 บรรทัด — หลังวางแล้วหน้าจออาจนิ่งไป 5–15 วินาที เป็นเรื่องปกติ รอให้เลขบรรทัดขึ้นครบก่อน แล้วค่อยกดบันทึก

กด Ctrl+S เพื่อบันทึก แล้วเปลี่ยนชื่อโปรเจกต์ตรงมุมบนซ้าย (ที่เขียนว่า โปรเจกต์ที่ไม่มีชื่อ) เป็น The M Corner AP

Android — Chrome → เมนู ⋮ → เพิ่มลงในหน้าจอหลัก
จะได้ไอคอนกดเปิดได้ทันที เปิดแล้วกด PIN 6 หลักเข้าได้เลยเหมือนแอปธนาคาร ถ่ายรูปแนบงานซ่อมจากกล้องได้ และระบบอ่านตัวเลขจากสลิปให้อัตโนมัติด้วย

🔴 ข้อมูลอัปเดตสด

ทุกหน้าจะเช็คทุก 25 วินาทีว่าชีตถูกแก้หรือยัง ถ้าเปลี่ยนก็โหลดใหม่ให้เอง ครอบคลุมทั้งการแก้ผ่านเว็บและการพิมพ์แก้ในชีตโดยตรง — มุมขวาบนจะมีจุด ● สด บอกว่ากำลังเช็คอยู่

👥 แจกให้คนอื่นเข้ามาดูหรือช่วยแก้

หน้า ⚙️ ตั้งค่า → 👥 ผู้ใช้ในระบบ → + เพิ่มผู้ใช้ ตั้งชื่อผู้ใช้ รหัสผ่านเริ่มต้น และสิทธิ์ แล้วส่งให้เจ้าตัว เขาเข้าที่ลิงก์เดียวกันได้เลย ระบบบังคับให้เปลี่ยนรหัสผ่านตอนเข้าครั้งแรก

สิทธิ์ทำอะไรได้
ดูอย่างเดียวเปิดดูได้ทุกหน้า แก้ไม่ได้ ดาวน์โหลดไฟล์สำรองไม่ได้
แก้ไขได้เพิ่ม แก้ ลบข้อมูลได้ แต่จัดการผู้ใช้และการตั้งค่าไม่ได้
ผู้ดูแลทำได้ทุกอย่าง รวมถึงจัดการผู้ใช้และการตั้งค่า

ระงับหรือลบบัญชีไหนก็ได้ทุกเมื่อ — กดปุ๊บเขาใช้ไม่ได้ปั๊บ แม้จะเปิดค้างไว้อยู่

⚙️ หน้าตั้งค่า · 🌗 ธีมสว่าง-มืด

เมนู ⚙️ ตั้งค่า ด้านซ้ายล่าง รวมทุกอย่างที่ปรับได้ไว้ที่เดียว 7 หมวด — ข้อมูลหอพัก · การแสดงผล · การแจ้งเตือน · การเงิน · ความปลอดภัย · การอ่านรูป · การสำรองข้อมูล
สลับ ธีมสว่าง / มืด / ตามเครื่อง ได้จากปุ่ม 🌗 มุมขวาบน ธีมจำแยกรายเครื่อง ตั้งบนมือถือกับบนคอมคนละแบบได้

🔎 แนบรูปแล้วให้ระบบกรอกให้

แนบสลิปโอนเงินหรือใบเสร็จในฟอร์มไหนก็ได้ แล้วกด 🔎 อ่านข้อความจากรูปนี้ ระบบจะเดา วันที่ · จำนวนเงิน · ชื่อร้าน · ชื่อรายการ · เลขอ้างอิง ให้ กดเติมทีละช่องหรือเติมทั้งหมดก็ได้ อ่าน พ.ศ. และเลขไทยได้ด้วย
ค่าที่ได้เป็นแค่ข้อเสนอ แก้เองได้เสมอ — ตรวจให้ตรงกับรูปก่อนกดบันทึกทุกครั้ง โดยเฉพาะรูปเอียงหรือถ่ายในที่มืดที่อ่านพลาดง่าย

💾 ข้อมูลปลอดภัยแค่ไหน

ข้อมูลจริงอยู่ใน Google Sheet ของคุณ แก้ในชีตตรง ๆ ได้ตลอด (แค่อย่าลบหัวตารางแถวแรก) ระบบยังเขียนไฟล์สำรองลงโฟลเดอร์ สำรองข้อมูล ใน Drive ทุกวันตอนตี 2 เก็บย้อนหลัง 30 ชุด และบันทึกทุกการเพิ่ม-แก้-ลบไว้ในแท็บ ActivityLog

อาการวิธีแก้
ในช่องเลือกฟังก์ชันไม่มี START_HERE ยังบันทึกไม่เสร็จ กด Ctrl+S รอสักครู่ แล้วกดที่ช่องเลื่อนใหม่อีกครั้ง
กด Run แล้วขึ้น Script function not found เหมือนข้อบน — โค้ดยังบันทึกไม่ครบ ลองบันทึกใหม่แล้วรีเฟรชหน้า Apps Script
หาปุ่ม “ขั้นสูง / Advanced” ไม่เจอ อยู่มุมซ้ายล่างของกล่องข้อความ เป็นตัวอักษรเล็ก ๆ ไม่ใช่ปุ่ม ต้องกดที่ข้อความนั้นตรง ๆ
ลืมรหัสผ่าน admin จนเข้าไม่ได้ เมนูในชีต 🏢 → 🔐 ตั้งรหัสผ่านผู้ดูแลใหม่ · หรือเปิด ลิงก์กู้ระบบ ที่มี ?key= ต่อท้าย
ใส่รหัสผิดหลายครั้งจนถูกล็อก รอ 15 นาที (ปรับได้ในหน้าตั้งค่า) หรือให้ผู้ดูแลกด แก้ไข ที่บัญชีนั้น ระบบจะปลดล็อกให้
ใส่ PIN ผิดจน PIN ถูกยกเลิก ตั้งใจให้เป็นแบบนั้น — เข้าด้วยรหัสผ่านตามปกติ แล้วตั้ง PIN ใหม่ในหน้าตั้งค่า
อ่านรูปแล้วได้ตัวเลขผิด แก้ในช่องได้เลย ค่าที่ได้เป็นแค่ข้อเสนอ · ถ่ายใหม่ให้ตรงและสว่างขึ้นจะแม่นกว่า
เปิดลิงก์แล้วหน้าขาว หรือขึ้น error กด Deploy → Manage deployments → ✏️ → Version: New version → Deploy เพื่อเผยแพร่รุ่นใหม่
ไม่มีเมนู 🏢 ในชีต โหลดหน้าชีตใหม่ด้วย F5 เมนูจะขึ้นหลังโหลดเสร็จประมาณ 2–3 วินาที
ข้อมูลเข้าซ้ำสองรอบ ไม่เกิดขึ้น ระบบข้ามให้เองถ้าชีตมีข้อมูลอยู่แล้ว รัน START_HERE ซ้ำได้ปลอดภัย
อยากให้คนอื่นแก้ไขข้อมูลได้ด้วย หน้า ⚙️ ตั้งค่า → 👥 ผู้ใช้ในระบบ → + เพิ่มผู้ใช้ เลือกสิทธิ์ “แก้ไขได้”
