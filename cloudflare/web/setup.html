① เชื่อมกับ Apps Script และย้ายข้อมูล

  1. ใน Apps Script วางโค้ด AllInOne.gs รุ่นล่าสุด แล้วกด Deploy → Manage deployments → ✏️ → Version: New version → Deploy
  2. คัดลอก Web app URL (ลงท้ายด้วย /exec) มาวางด้านล่าง
  3. วาง ลิงก์กู้ระบบ ทั้งเส้น (ลงท้ายด้วย ?key=…) — อยู่ในระบบเดิม หน้า ⚙️ ตั้งค่า เลื่อนลงล่างสุดของหัวข้อลิงก์แชร์ ตรงบรรทัด 🆘 ลิงก์กู้ระบบ · หรือเปิด Google Sheet แผ่น Settings แถว admin_token แล้วคัดลอกช่องค่า

② ตรวจว่าข้อมูลสองฝั่งตรงกัน

เทียบทุกแถวของทุกแผ่นงาน และตัวเลขสรุปที่หน้าระบบแสดง (ยอดหนี้ ค่าใช้จ่าย รายรับ-รายจ่าย ฯลฯ)
ซ่อมเมื่อไม่ตรง

ส่งข้อมูลทั้งหมดของ Cloudflare (ตัวหลัก) ไปทับ Apps Script

③ เปิดใช้งาน

เปิดระบบบน Cloudflare →

ล็อกอินด้วยชื่อผู้ใช้และรหัสผ่านเดิมได้เลย (PIN ประจำเครื่องต้องตั้งใหม่ในเครื่องที่เปิดลิงก์นี้) · บนมือถือกด "เพิ่มลงหน้าจอโฮม" แล้วใช้เหมือนแอป
