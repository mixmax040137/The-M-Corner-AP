# 📦 ติดตั้งระบบบน Google (ทำครั้งเดียว ~10 นาที)

จบขั้นตอนนี้แล้วจะได้ **ลิงก์ 2 อัน**

- 🔑 **ลิงก์ผู้ดูแล** — เพิ่ม/แก้/ลบข้อมูลได้ทุกอย่าง (เก็บไว้ใช้เอง)
- 👀 **ลิงก์แชร์** — เปิดดูได้อย่างเดียว ส่งให้ใครก็ได้ ไม่ต้องมีบัญชี Google และไม่เห็น Google Sheet ของคุณ

ข้อมูลทั้งหมดอยู่ใน Google Sheet ของคุณเอง ใครแก้อะไรก็เห็นตรงกันทันที

---

## ของที่เตรียมไว้ให้แล้ว

| อะไร | ลิงก์ |
|---|---|
| 📁 โฟลเดอร์ | [The M Corner AP](https://drive.google.com/drive/folders/1jIGt_ebYv-8TvIrSoRrsp1QPnDZ9-kMM) |
| 📊 Google Sheet (ฐานข้อมูล) | [The M Corner AP — ฐานข้อมูล](https://docs.google.com/spreadsheets/d/1frGWki1sBDG3T4eJxNm5wUZQkXUFcdEIPwKZLaQuSrg/edit) |

ชีตยังว่างอยู่ — ขั้นตอนที่ 5 จะสร้างตารางและใส่ข้อมูลเดิมให้ครบเอง

---

## ขั้นตอนที่ 1 — เปิดตัวแก้ไขสคริปต์

1. เปิด [Google Sheet](https://docs.google.com/spreadsheets/d/1frGWki1sBDG3T4eJxNm5wUZQkXUFcdEIPwKZLaQuSrg/edit)
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. จะเปิดแท็บใหม่ที่มีไฟล์ `Code.gs` และโค้ดตัวอย่างไม่กี่บรรทัด
4. ตั้งชื่อโปรเจกต์ (มุมบนซ้าย เขียนว่า *Untitled project*) เป็น **`The M Corner AP`**

---

## ขั้นตอนที่ 2 — วางโค้ดฝั่งเซิร์ฟเวอร์

1. เปิดไฟล์ [`build/Code.gs`](../build/Code.gs) ใน GitHub → กดปุ่ม **Copy raw file** (ไอคอนสองแผ่นซ้อนกัน มุมขวาบนของกล่องโค้ด)
2. กลับมาที่ Apps Script → คลิกในไฟล์ `Code.gs` → **เลือกทั้งหมด (Ctrl+A / ⌘A) แล้วลบ**
3. **วาง (Ctrl+V / ⌘V)** โค้ดที่คัดลอกมา
4. กด 💾 บันทึก

> ไฟล์ยาวประมาณ 3,200 บรรทัด รอสักครู่ให้ตัวแก้ไขโหลดจนเสร็จ

---

## ขั้นตอนที่ 3 — วางหน้าเว็บ

1. ในแถบไฟล์ทางซ้าย กด **+ → HTML**
2. ตั้งชื่อไฟล์ว่า **`Index`** (พิมพ์แค่นี้ ไม่ต้องใส่ `.html`)
3. เปิด [`build/Index.html`](../build/Index.html) ใน GitHub → **Copy raw file**
4. กลับมาที่ไฟล์ `Index` → เลือกทั้งหมด ลบ แล้ววางทับ
5. กด 💾 บันทึก

> ⚠️ ชื่อไฟล์ต้องเป็น `Index` เป๊ะ ๆ เพราะโค้ดเรียกด้วยชื่อนี้

---

## ขั้นตอนที่ 4 — อนุญาตสิทธิ์และสร้างตาราง

1. เลือกฟังก์ชัน **`setupSystem`** จากช่องเลื่อนด้านบน แล้วกด **▶ Run**
2. ครั้งแรกจะขึ้นขออนุญาต:
   **Review permissions → เลือกบัญชีของคุณ → Advanced → Go to The M Corner AP (unsafe) → Allow**
   *(ที่ขึ้นว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ส่งให้ Google ตรวจ — ปลอดภัย)*
3. รอจนขึ้นว่า **ติดตั้งระบบเรียบร้อย** พร้อมรายชื่อชีต 11 แท็บ

---

## ขั้นตอนที่ 5 — นำเข้าข้อมูลเดิม

เลือกฟังก์ชัน **`seedHistoricalData`** แล้วกด **▶ Run**

จะได้ข้อความยืนยัน:

```
• ก้อนหนี้: 4 รายการ
• รายการโอนใช้หนี้: 40 รายการ
• รายการซื้อของ: 94 รายการ
• ล้างแอร์: 41 ครั้ง
• ซ่อมแซมตามห้อง: 42 รายการ
• ซ่อมแซมตึกโดยรวม: 4 รายการ
• รายรับ-รายจ่ายรายเดือน: 32 รายการ
• ทรัพย์สินประจำห้อง: 72 รายการ
```

> รันซ้ำไม่ได้โดยตั้งใจ ถ้าชีตมีข้อมูลอยู่แล้วระบบจะข้ามให้เอง ไม่ทำข้อมูลซ้ำ

---

## ขั้นตอนที่ 6 — Deploy เป็นเว็บแอป

1. มุมบนขวา กด **Deploy → New deployment**
2. กดรูปเฟือง ⚙️ ข้าง *Select type* → เลือก **Web app**
3. ตั้งค่าให้ตรงตามนี้:

   | ช่อง | ใส่ว่า |
   |---|---|
   | Description | `v1` |
   | Execute as | **Me (อีเมลของคุณ)** |
   | Who has access | **Anyone** |

4. กด **Deploy** → กด **Authorize access** ถ้าถูกถามอีกครั้ง
5. กด **Done**

> **"Anyone" ปลอดภัยไหม?** ปลอดภัย — ลำพัง URL เปล่า ๆ เปิดแล้วจะเจอหน้า 🔒 *ไม่มีสิทธิ์เข้าใช้งาน*
> ต้องมี `?key=...` ที่ถูกต้องต่อท้ายเท่านั้นถึงจะเข้าได้ และการกันสิทธิ์ทำที่ฝั่งเซิร์ฟเวอร์
> เลือก "Anyone" เพื่อให้คนที่รับลิงก์แชร์ไปไม่ต้องมีบัญชี Google

---

## ขั้นตอนที่ 7 — รับลิงก์ทั้งสองอัน

1. กลับไปที่แท็บ Google Sheet แล้ว **โหลดหน้าใหม่ (F5)**
2. จะมีเมนูใหม่ชื่อ **🏢 The M Corner AP** โผล่ขึ้นมาบนแถบเมนู
3. เลือก **🔗 แสดงลิงก์เข้าใช้งาน**
4. จะได้กล่องข้อความที่มีลิงก์ 2 อัน — คัดลอกเก็บไว้

```
🔑 ลิงก์ผู้ดูแล (แก้ไขข้อมูลได้ — เก็บไว้ใช้เอง)
https://script.google.com/macros/s/.../exec?key=xxxxxxxx

👀 ลิงก์แชร์ (ดูอย่างเดียว — ส่งให้คนอื่นได้)
https://script.google.com/macros/s/.../exec?key=yyyyyyyy
```

**เสร็จแล้ว** 🎉 เปิดลิงก์ผู้ดูแลได้เลย

## ใช้บนมือถือให้เหมือนแอป

1. เปิด **ลิงก์ผู้ดูแล** บนมือถือ
2. **iPhone**: Safari → ปุ่มแชร์ ⬆️ → *เพิ่มไปยังหน้าจอโฮม*
   **Android**: Chrome → เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก*
3. ได้ไอคอนเปิดระบบทันที ถ่ายรูปแนบจากกล้องได้เลย

## เรื่องที่ควรรู้

### ข้อมูลอัปเดตสดยังไง
หน้าเว็บจะถามเซิร์ฟเวอร์ทุก 25 วินาทีว่าชีตถูกแก้หรือยัง ถ้าเปลี่ยนก็โหลดข้อมูลใหม่ให้เอง
รวมถึงตอนคุณพิมพ์แก้ในชีตโดยตรงด้วย — คนที่เปิดลิงก์แชร์ค้างไว้จะเห็นของใหม่ภายในไม่เกินครึ่งนาที
(ปรับความถี่ได้ที่ชีต `Settings` → `refresh_seconds` ใส่ 0 เพื่อปิด)

### แก้โค้ดแล้วเว็บไม่เปลี่ยน
ต้อง **Deploy → Manage deployments → ✏️ (แก้ไข) → Version: New version → Deploy** ทุกครั้ง
ลิงก์เดิมใช้ได้ต่อ ไม่ต้องแจกใหม่

### ใครแก้อะไรบ้าง
ดูได้ที่ชีต `ActivityLog` — บันทึกทุกการเพิ่ม/แก้/ลบ พร้อมเวลา

### แก้ข้อมูลในชีตโดยตรงได้ไหม
ได้เลย ระบบอ่านจากชีตตลอด แค่อย่าลบหรือสลับหัวตารางแถวแรก

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น 🔒 ไม่มีสิทธิ์เข้าใช้งาน | ลิงก์ขาด `?key=...` หรือกุญแจไม่ตรง — เอาลิงก์จากเมนู **แสดงลิงก์เข้าใช้งาน** อีกครั้ง |
| ไม่มีเมนู 🏢 ในชีต | โหลดหน้าชีตใหม่ (F5) ถ้ายังไม่มี ให้รัน `onOpen` จาก Apps Script หนึ่งครั้ง |
| กด Run แล้วขึ้น `Script function not found` | ยังบันทึกไฟล์ไม่ครบ กด 💾 แล้วเลือกฟังก์ชันใหม่จากช่องเลื่อน |
| อัปโหลดรูปแล้วไม่ขึ้น | ไฟล์เกิน 12 MB — ถ่ายด้วยความละเอียดต่ำลง |
| วันที่เพี้ยน | ระบบอ่านได้ทั้ง `26/04/26`, `5/20/2026` และ พ.ศ. `19/01/2565` ถ้ายังเพี้ยนให้กรอกเป็น `YYYY-MM-DD` |
| อยากให้คนอื่นแก้ไขได้ด้วย | ใส่อีเมลเขาในชีต `Settings` แถว `admin_emails` (คั่นด้วย `,`) แล้วให้เขาเปิดลิงก์ผู้ดูแล |

## สำหรับคนที่ใช้ clasp ได้

```bash
npm install -g @google/clasp
clasp login
clasp clone <scriptId>        # ดู scriptId ได้จาก Apps Script → Project Settings
cp -r src/* .                 # ใช้ไฟล์แยกตามโมดูล ไม่ต้องใช้ build/
clasp push
```

ไฟล์ใน `src/` แยกเป็นโมดูลอ่านง่ายกว่า ส่วน `build/` มีไว้สำหรับคัดลอกวางเท่านั้น
