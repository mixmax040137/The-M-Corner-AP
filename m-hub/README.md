# M Hub — ศูนย์รวมเครื่องมือทำงาน

**เปิดใช้งาน:** https://m-hub.mcorner-ap.workers.dev

เว็บแอปที่รวมงานซ้ำ ๆ ไว้ในที่เดียว ทำงานบนเครื่องของผู้ใช้ทั้งหมด (ไฟล์ไม่ถูกอัปโหลดไปไหน) ติดตั้งเป็นโปรแกรมได้ ใช้ออฟไลน์ได้หลังเปิดครั้งแรก และออกแบบให้เพิ่มเครื่องมือใหม่ได้เรื่อย ๆ

เป็น Cloudflare Worker ตัวใหม่ชื่อ `m-hub` ในบัญชีส่วนตัว **แยกจากระบบเดิมทั้งหมด** (`m-corner-ap`, `moneyflow`, `design` ไม่ถูกแตะ) โค้ดทั้งหมดอยู่ในโฟลเดอร์นี้

### จุดที่ควรรู้
- **เชื่อมโฟลเดอร์ในเครื่องโดยตรง** ใช้ได้บน Chrome / Edge บนคอมพิวเตอร์ (เบราว์เซอร์อื่นยังใช้ได้ทุกเครื่องมือ โดยรับผลเป็น ZIP)
- **บันทึกลงโฟลเดอร์ไม่เขียนทับไฟล์เดิม** ชื่อซ้ำจะต่อท้าย (2), (3)
- **HEIC:** รับเป็นไฟล์ต้นทางได้ แต่ไม่มีเบราว์เซอร์ใดสร้างไฟล์ .HEIC ได้ จึงใช้ **AVIF** (ตระกูล HEIF เดียวกัน ไฟล์เล็กกว่า) แทน
- **PDF ที่เป็นภาพสแกน** ไม่มีข้อความให้ดึง ระบบจะเตือนและให้กรอกเอง
- **PDF จาก Chrome / Google Docs** มักทำวรรณยุกต์ไทยหาย ระบบซ่อมให้อัตโนมัติด้วยพจนานุกรมไทยในเบราว์เซอร์ (ไม่ใช้ AI) — ควรตรวจทานทุกครั้ง
- **ข้อความที่แปลด้วย AI ต้องตรวจทานก่อนส่งเสมอ** (ใช้โควตาฟรีของ Workers AI ในบัญชี และรับเฉพาะคำขอจากหน้าเว็บ M Hub เอง)
- **OCR** ครั้งแรกต้องโหลดตัวอ่าน + ข้อมูลภาษาไทยประมาณ 5 MB (เบราว์เซอร์จำไว้ ครั้งต่อไปเร็วและใช้ออฟไลน์ได้) · ภาพชัด ตรง ตัวหนังสือใหญ่ จะอ่านแม่นที่สุด
- **วิดีโอ** ใช้ WebCodecs ของเบราว์เซอร์ (Chrome / Edge แนะนำ) · ถ้าเบราว์เซอร์สร้างเสียง AAC ไม่ได้ ระบบจะเตือนว่าไฟล์ MP4 ใช้เสียง Opus (บาง iPhone อาจไม่มีเสียง)
- **QR** ทดสอบสแกนด้วยตัวอ่าน QR อัตโนมัติแล้ว รวมถึงข้อความภาษาไทย
- **เครื่องมือภาพแบบ Canva**
  - *ในเครื่อง (ไม่ต้องใช้เน็ตหลังโหลดครั้งแรก)*: ปรับแต่ง/ฟิลเตอร์, ยางลบวิเศษแบบในเครื่อง, เบลอ, รีทัชผิว, ลบ/เบลอพื้นหลัง, หยิบบุคคล, ดึงข้อความ, ขยายภาพด้วย AI — ใช้ TensorFlow.js กับโมเดล Robust Video Matting (แยกบุคคล ~4 MB) และ ESRGAN (ขยายภาพ ~1 MB) โหลดผ่าน `/cdn/` ครั้งแรกแล้วเบราว์เซอร์จำไว้
  - การแยกพื้นหลัง/หยิบวัตถุ **รองรับบุคคลเป็นหลัก** (โมเดลทั่วไปสำหรับสิ่งของใหญ่และหนักเกินกว่าจะโหลดในเบราว์เซอร์)
  - *AI สร้างภาพ (ใช้เน็ต)*: แก้ด้วยคำสั่ง, ยางลบแบบ AI, สร้างพื้นหลังใหม่, ขยายขอบภาพ, เติมพื้นหลังตอนหยิบบุคคล — ใช้ FLUX.2 [klein] 4B ผ่าน Workers AI ของบัญชีนี้ (โควตาฟรี 10,000 neurons/วัน ใช้ร่วมกับการแปล — ประมาณ 30–40 ครั้งต่อวันสำหรับเครื่องมือ AI ภาพ, รีเซ็ต 07:00 น. เวลาไทย; เมื่อหมดจะขึ้นข้อความแจ้ง เครื่องมือที่ไม่ใช้ AI ยังใช้ได้ปกติ) ส่งภาพไป Cloudflare **เฉพาะตอนกดใช้เครื่องมือ AI** · ผลแต่ละครั้งไม่เหมือนกัน ไม่ถูกใจกด Ctrl+Z แล้วลองใหม่ · คำสั่งภาษาไทยจะแปลเป็นอังกฤษก่อนส่ง
  - หน้าต่างแก้ไขทีละรูปทำงานที่ด้านยาวไม่เกิน 2400 px (ขยายภาพด้วย AI ได้ถึง 6000 px)
- ค่าตั้ง พรีเซ็ต และฟอนต์ที่เพิ่ม จำไว้ในเบราว์เซอร์ของเครื่องนั้น

## L'Arts PR Writer

เครื่องมือเขียนโพสต์สำหรับหน่วยประชาสัมพันธ์ คณะศิลปศาสตร์ มหาวิทยาลัยธรรมศาสตร์ อยู่ในเมนูซ้ายของ M Hub (ลิงก์ตรง: https://m-hub.mcorner-ap.workers.dev/#/pr-writer) ไม่ต้องล็อกอิน ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

**สถานะ:** เฟส 1 เสร็จ (โหมดเทมเพลต ฟอร์ม เทมเพลต โทน ช่องทาง ตั้งค่า ส่งออก/นำเข้า QR ตัวตรวจก่อนโพสต์) · เฟส 2 เสร็จ (ฐานข้อมูลบุคลากร แนวทางการเขียน แจ้งเปลี่ยนแปลงพร้อมประวัติเวอร์ชัน ปฏิทินและชุดโพสต์ ข้อความโปสเตอร์) · เฟส 3 เสร็จ (โหมด AI: อ่านไฟล์ → ดึงข้อมูล, เขียน 2 แบบ, ขัดเกลา, คลังโพสต์และตัวอย่าง, ประมาณ token, แคช) · เฟส 4 สถิติและรายงานรายเดือน

### ใช้งาน
1. **ภาพรวม** บอกงานที่กำลังจะถึง และแนะนำว่าควรโพสต์อะไรต่อ (เช่น ใกล้ปิดรับลงทะเบียน งานพรุ่งนี้ งานจบแล้วยังไม่มีโพสต์สรุป) คำนวณจากวันที่ ไม่ใช้ AI
2. **เขียนโพสต์** เลือกงาน (หรือ “งานใหม่”) กรอกฟอร์ม เลือกประเภท โทน ภาษา และช่องทาง ข้อความจะสร้างทันทีและแก้ในกล่องได้
   - เลือกภาษาอังกฤษหรือสองภาษา ฟอร์มจะมีช่องภาษาอังกฤษคู่กัน ปุ่ม “เติมช่องภาษาอังกฤษ” แปลด้วยคลังคำแปลของ M Hub และ AI ฟรีของ Cloudflare (ไม่แปลชื่อบุคคล)
   - ช่องที่จำเป็นแต่ยังว่างจะขึ้นเป็น `[กรอก: …]` ในข้อความ
   - ช่องทาง “ทุกช่องทาง” แสดงข้อความครบ 8 ช่องทางพร้อมกัน
   - อีเมล: เปิดใน Gmail / Outlook หรือดาวน์โหลด .eml · หนังสือเวียนใช้ภาษาแบบราชการเสมอ
   - “บันทึกร่าง” / “ใช้จริง” เก็บโพสต์ไว้กับงาน (ดูและเปลี่ยนสถานะได้ในหน้า “งานทั้งหมด”)
3. **ควรเช็ก** (ตรวจทุกครั้งที่ข้อความเปลี่ยน ไม่ใช้ token):
   - วันในสัปดาห์ตรงกับวันที่ไหม อ่านได้ทั้ง “วันจันทร์ที่ 15 ธันวาคม 2569”, “๑๕ ธ.ค. ๖๙ (จ.)”, “15/12/2569”, “Monday, 15 December 2026” และช่วงวันที่ พร้อมปุ่มแก้ให้
   - ข้อความไทยใช้ พ.ศ. / ข้อความอังกฤษใช้ ค.ศ., วันที่ไม่มีจริง, ปีที่ห่างจากปัจจุบันผิดปกติ, วันที่ไม่ตรงกับข้อมูลงาน, เวลาจบก่อนเวลาเริ่ม
   - ลิงก์: รูปแบบ (ไม่มี https://, มีตัวอักษรไทยติดท้าย) และ **ตรวจว่าเปิดได้จริงผ่าน Worker** (`/api/linkcheck`) — ยังไม่ได้ตรวจจะไม่บอกว่าใช้ได้, ตรวจไม่ได้จะบอก “ตรวจไม่ได้”, ฟอร์ม Google ที่ปิดรับแล้วจะเตือน, ลิงก์ Zoom/Meet ตรวจได้แค่ว่าหน้าเว็บเปิดได้
   - คำต้องห้ามพร้อมคำแนะนำแทน, การกล่าวถึงคณะครั้งแรกต้องใช้ชื่อเต็ม, ช่องที่ยังไม่กรอก, ความยาว/แฮชแท็ก/อีโมจิตามช่องทางและโทน, ครับ–ค่ะปนกัน, เลขไทยปนอารบิก
4. **เทมเพลต** ดูต้นแบบทุกประเภท/โทน/ภาษา กด “คัดลอกไปแก้” แล้วติ๊ก “ใช้แทนต้นแบบ” หน้าเขียนโพสต์จะใช้ของคุณแทน
   - `{{title}}` แทนด้วยข้อมูล (ว่าง = ลบทั้งบรรทัด) · `{{title!}}` ว่างแล้วขึ้น `[กรอก: …]` · `{{audience|ผู้สนใจ}}` ค่าแทนเมื่อว่าง · `[[ … ]]` ส่วนเสริมที่ถูกตัดเมื่อข้อมูลข้างในว่าง
5. **บุคลากร** ตารางชื่อ คำนำหน้า/ตำแหน่งวิชาการ ตำแหน่ง ทั้งไทยและอังกฤษ หน่วยงาน อีเมล โทร · นำเข้า/ส่งออก CSV หรือ Excel (ชื่อไทยที่มีอยู่จะถูกอัปเดต)
   - ในหน้าเขียนโพสต์ พิมพ์ชื่อในช่องประธาน วิทยากร หรือผู้ประสานงาน แล้วเลือกจากรายชื่อ ระบบใส่ชื่อพร้อมตำแหน่งให้ถูกตามภาษา (เช่น “รองศาสตราจารย์ ดร.อรุณี …” / “Assoc. Prof. Dr. Arunee …, Dean”)
   - ตัวตรวจ “ควรเช็ก” เตือนเมื่อโพสต์เขียนตำแหน่งวิชาการไม่ตรงกับฐานข้อมูล เช่น เขียน “อาจารย์ ดร.” แต่ฐานข้อมูลเป็น “ผู้ช่วยศาสตราจารย์ ดร.” พร้อมปุ่มแก้
6. **แนวทางการเขียน** ชื่อคณะไทย/อังกฤษ, ถ้อยคำบังคับ (ชื่อเต็มครั้งแรก / ต้องมี), คำต้องห้ามหรือไม่แนะนำพร้อมคำแนะนำแทน, ชุดแฮชแท็กตามช่องทางและประเภทงาน, ลายเซ็น, คำอธิบายโทน (ใช้กับโหมด AI)
7. **แก้ไขและแจ้งเปลี่ยนแปลง** (ปุ่มในหน้าเขียนโพสต์และหน้างานทั้งหมด) เก็บข้อมูลเดิมเป็นเวอร์ชัน แล้วแก้เฉพาะช่องที่เปลี่ยน ระบบเขียนประกาศแจ้งเปลี่ยนแปลงให้: ค่าเดิม → ค่าใหม่ของช่องที่เปลี่ยน, ข้อมูลสำคัญที่คงเดิมมี “(ไม่เปลี่ยนแปลง)”, คำขออภัย, หัวเรื่องอีเมลขึ้นต้น “[แจ้งเปลี่ยนแปลง]” (0 token) · ดูประวัติเวอร์ชันและย้อนกลับได้ในหน้างานทั้งหมด
8. **ปฏิทินโพสต์** มุมมองเดือน/รายการ กรองสถานะ ร่าง · อนุมัติแล้ว · โพสต์แล้ว คลิกโพสต์เพื่อแก้ข้อความ วันที่ และสถานะ
   - **สร้างชุดโพสต์** 5 ชิ้นต่องาน: ประกาศล่วงหน้า (14 วันก่อน), เตือนก่อนปิดรับ (2 วันก่อนปิดรับ), 1 วันก่อนงาน, วันงาน, สรุปหลังงาน — วันที่แนะนำแก้ได้ ชิ้นที่วันผ่านไปแล้วไม่ถูกเลือก ทุกชิ้นเขียนด้วยเทมเพลต
   - ในหน้าเขียนโพสต์กำหนด “วันที่จะโพสต์” ก่อนกดบันทึก โพสต์จะขึ้นในปฏิทิน
9. **ข้อความโปสเตอร์** พาดหัว (นับคำด้วยตัวตัดคำภาษาไทย เตือนเมื่อเกิน 8 คำ และเสนอพาดหัวที่สั้นลงจากชื่องาน), หัวรอง, วัน-เวลา-สถานที่, คำชวน, ลิงก์/QR พร้อมตัวอย่างโปสเตอร์คร่าว ๆ · คัดลอก/ดาวน์โหลด .txt หรือกด “ส่งไปทำภาพปกโพสต์” เพื่อทำภาพต่อในเครื่องมือภาพปกของ M Hub
10. **โหมด AI** (หน้าเขียนโพสต์ → วิธีเขียน “AI เขียน 2 แบบ”)
   - **เริ่มจากไฟล์หรือข้อความ:** ลาก PDF, Word (.docx) หรือรูปโปสเตอร์มาวาง หรือวางข้อความ ระบบอ่านในเครื่องก่อน (PDF/Word อ่านตรง, รูปและ PDF สแกนใช้ OCR ภาษาไทย) แล้วแยกชื่องาน วันที่ เวลา สถานที่ ลิงก์ วันปิดรับ เบอร์โทร อีเมล โดยไม่ใช้ AI ให้เลือกช่องที่จะใส่ลงฟอร์ม — ถ้าต้องการให้ครบกว่านั้นกด “ให้ AI แยกข้อมูลจากข้อความ” (ส่งเฉพาะข้อความ ไม่ส่งไฟล์) หรือ “ให้ AI อ่านจากรูปโดยตรง” (เฉพาะ Claude ใช้เมื่อ OCR อ่านได้ไม่ดี)
   - **AI เขียน 2 แบบ:** ส่งเฉพาะช่องที่กรอกแล้ว + โทน ภาษา ช่องทาง + กฎของคณะแบบสั้น + โพสต์ในคลังที่คล้ายที่สุดไม่เกิน 3 โพสต์ ได้ 2 แบบวางเทียบกัน แต่ละแบบมีตัวตรวจ “ควรเช็ก” ของตัวเอง ปุ่มคัดลอก / ใช้จริง / บันทึกร่าง / ขัดเกลา (ใช้รุ่นสำหรับขัดเกลา ย้อนกลับได้)
   - ก่อนกดแสดง token และค่าใช้จ่ายโดยประมาณเสมอ กด “ดูข้อความที่จะส่งให้ AI” เพื่อดูทุกอย่างที่ส่งได้ · ข้อมูลและตัวเลือกเดิมจะใช้ผลเดิมจากแคช ไม่เรียก AI ซ้ำ
   - คำสั่งระบบใช้ตามที่หน่วยงานกำหนด (ตอบเป็น JSON: variant1, variant2, check)
11. **คลังโพสต์** โพสต์ที่กด “ใช้จริง” (ฉบับที่แก้แล้ว) และโพสต์สถานะ “โพสต์แล้ว” ค้นหา/กรอง ติดแท็ก เลือกว่าจะใช้เป็นตัวอย่างให้ AI หรือไม่ “ใช้เป็นเทมเพลต” (แทนข้อมูลงานด้วย {{ตัวแปร}} ให้) และ “เพิ่มโพสต์ที่เคยโพสต์” เพื่อให้ AI เรียนสำนวนของคณะ
12. **QR Code** เลือกลิงก์จากงานหรือวางลิงก์ ใส่โลโก้คณะตรงกลางได้ (จำไว้ในเบราว์เซอร์) ดาวน์โหลด PNG/SVG 512–2048 px

### AI: ฟรี หรือ Claude
- **ไม่ต้องใช้ AI ตลอด:** เทมเพลต ตัวตรวจ บุคลากร แจ้งเปลี่ยนแปลง ปฏิทิน โปสเตอร์ QR ไม่ใช้ AI เลย AI ทำงานเฉพาะตอนกดปุ่ม AI
- **AI ฟรี (Cloudflare Workers AI):** ใช้ได้ทันทีไม่ต้องมี key ผ่าน Worker ของ M Hub (`/api/ai/chat` รับเฉพาะคำขอจากหน้าเว็บ M Hub) ใช้โควตาฟรีรายวันของบัญชีร่วมกับการแปลและ AI รูปภาพ (รีเซ็ต 07:00 น.) ภาษาไทยด้อยกว่า Claude เหมาะเป็นร่างแรก · ลองรุ่น DeepSeek V4 Flash → Kimi K2.6 → Llama 3.3 70B ตามลำดับถ้ารุ่นก่อนใช้ไม่ได้ · อ่านรูปโดยตรงไม่ได้ (ใช้ข้อความจาก OCR แทน)
- **Claude (มีค่าใช้จ่ายตามใช้):** สมัครที่ console.anthropic.com เติมเครดิตล่วงหน้า (ค่าสมาชิก Claude Pro/Max ใช้แทนค่า API ไม่ได้) ไปที่ **ตั้งค่า → AI** วาง API key แล้วกด “บันทึก” key เก็บใน localStorage ของเบราว์เซอร์นั้นเท่านั้น ไม่อยู่ในโค้ด ไม่อยู่ใน git และไม่อยู่ในไฟล์สำรองข้อมูล ใช้คนละเครื่องต้องใส่ใหม่ · แนะนำสร้าง key แยกสำหรับงานนี้และตั้งวงเงินรายเดือนใน Console
- รุ่นเริ่มต้น: ร่าง = Claude Haiku 5.5 ($0.10/$0.50 ต่อล้าน token ปิดโหมดคิด effort ต่ำ), ขัดเกลา = Claude Sonnet 5.5 ($2/$10 ปิดโหมดคิด effort ต่ำ) เปลี่ยนแต่ละช่องเป็น AI ฟรีหรือรุ่นอื่นได้ · ยังไม่ใส่ key ระบบใช้ AI ฟรีแทนให้อัตโนมัติ
- ค่าใช้จ่ายโดยประมาณ: เขียน 2 แบบ ~2–3 สตางค์, ขัดเกลา ~25 สตางค์, อ่านรูป 1 รูป ~1 สตางค์ · ยอดจริงรายเดือน (ครั้ง, token, ดอลลาร์) อยู่ในหน้าตั้งค่า
- เบราว์เซอร์เรียก Anthropic API โดยตรงด้วย Anthropic SDK (`@anthropic-ai/sdk` รวมไว้ที่ `public/vendor/anthropic.mjs` โหลดเฉพาะตอนกดใช้ AI)

### สำรองและย้ายข้อมูล
ข้อมูลทั้งหมด (งาน เทมเพลต โพสต์ ค่าตั้ง) อยู่ใน IndexedDB ของเบราว์เซอร์ ไปที่ **ตั้งค่า → ส่งออกข้อมูลทั้งหมด** จะได้ไฟล์ `larts-pr-backup-วันที่.json` ไฟล์เดียว ควรสำรองเป็นระยะ · **นำเข้าจากไฟล์** ใช้ย้ายเครื่องหรือรวมข้อมูลจากเพื่อนร่วมงาน รายการเดียวกันจะใช้ฉบับที่แก้ล่าสุด · ชั้นเก็บข้อมูล (`public/pr/db.js`) แยกจากหน้าจอ ภายหลังต่อ Google Sheets ได้โดยไม่ต้องแก้หน้าจอ

### ข้อมูลตัวอย่าง
ครั้งแรกจะมีงานตัวอย่าง 3 งาน (สัมมนา ประชุม ค่าย) บุคลากรตัวอย่าง 7 คน และโพสต์ตัวอย่างในคลัง 3 โพสต์ ติดป้าย “ตัวอย่าง” ชื่อบุคคล เบอร์โทร อีเมล และลิงก์เป็นของสมมติทั้งหมด (ลิงก์ลงทะเบียนตัวอย่างจึงถูกตัวตรวจแจ้งว่าเปิดไม่ได้ และงานค่ายตั้งใจเขียนตำแหน่งวิชาการของวิทยากรไม่ตรงฐานข้อมูล เพื่อให้เห็นตัวตรวจทำงาน) ลบได้ในหน้าภาพรวมหรือตั้งค่า

└─ test/                   e2e.mjs (ทดสอบทุกเครื่องมือในเบราว์เซอร์), pr-unit.mjs (ตรรกะ PR Writer), live.mjs (ทดสอบเว็บจริง)

## เพิ่มเครื่องมือใหม่
1. สร้างไฟล์ `public/tools/<ชื่อ>.js`
   ```js
   import { h, btn, step, toast } from '../core/ui.js';
   export function mount(root) {
     root.append(step(1, 'ขั้นแรก', btn('ทำงาน', () => toast('สวัสดี'), { kind: 'primary' })));
   }
   ```
2. เพิ่ม 1 รายการใน `public/tools/registry.js` (id, ชื่อ, ไอคอน, คำอธิบาย, `load: () => import('./<ชื่อ>.js')`)
3. ทดสอบในเครื่อง แล้ว deploy (ด้านล่าง)

หรือบอก Claude ว่าอยากได้เครื่องมืออะไร — ไอเดียถัดไปแสดงในหน้าแรก (ตัดพื้นหลังรูป, รายงานสรุปกิจกรรม, ลายเซ็นอีเมลหน่วยงาน)

## พัฒนาและ deploy
```bash
cd m-hub
npm install
node test/server.mjs        # เปิด http://127.0.0.1:8788 (ต้องรัน npm run vendor ก่อนครั้งแรก)
npm test                    # ตรรกะ PR Writer + ทดสอบทุกเครื่องมือในเบราว์เซอร์ (Playwright) — ดึงไฟล์โมเดลสำหรับเทสต์ไว้ที่ test/cache/ ให้อัตโนมัติ
node test/e2e.mjs pr        # ทดสอบเฉพาะ L'Arts PR Writer เฟส 1 (pr2 = เฟส 2, pr3 = เฟส 3 โหมด AI จำลอง Claude API)
npm run deploy              # vendor → embed → wrangler deploy ไปบัญชีส่วนตัว
node test/live.mjs          # ทดสอบเว็บจริงหลัง deploy
```
หมายเหตุ: หน้าเว็บถูกฝังในสคริปต์ Worker (ไม่ใช้ Workers Static Assets) ขนาดหลังบีบอัด ~2.1 MB จากเพดานแผนฟรี 3 MB (`scripts/embed.mjs` จะหยุดถ้าเกิน) — ไฟล์ใหญ่ที่ใช้เฉพาะบางงาน (ตัวเข้ารหัส AVIF, ตัวอ่าน OCR + ข้อมูลภาษา, TensorFlow.js + โมเดลแยกบุคคล/ขยายภาพ) ให้ Worker ดึงจาก jsDelivr ที่ `/cdn/*` แทน โดยอนุญาตเฉพาะไฟล์ในรายการ (`CDN` ใน `src/worker.js`) และแคชไว้ที่ขอบเครือข่าย Cloudflare
