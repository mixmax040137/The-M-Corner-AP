| ลิงก์ | ใครใช้ | ทำอะไรได้ |
|---|---|---|
| 🔑 **ลิงก์ผู้ดูแล** | คุณคนเดียว | เพิ่ม/แก้/ลบได้ทุกอย่าง |
| 👀 **ลิงก์แชร์** | ส่งให้ใครก็ได้ | เปิดดูอย่างเดียว ไม่ต้องมีบัญชี Google และไม่เห็น Google Sheet ของคุณ |

- **ข้อมูลอยู่ใน Google Sheet ของคุณเอง** พร้อมสำรอง JSON ลง Drive อัตโนมัติทุกวัน
- **เปิดบนมือถือได้** กด "เพิ่มลงหน้าจอโฮม" แล้วใช้เหมือนแอป

### ส่วนที่เพิ่มให้เพื่อให้ระบบสมบูรณ์

- 📊 **แดชบอร์ดรวม** — ยอดหนี้คงเหลือ · ค่าใช้จ่ายปีนี้ · งานซ่อมค้าง · ห้องที่ยังไม่ล้างแอร์ ในหน้าเดียว
- 🔔 **ศูนย์แจ้งเตือน** — งานซ่อมค้างเกินกำหนด · ห้องถึงรอบล้างแอร์ · ประกันสินค้าใกล้หมดอายุ · งานตึกที่ครบรอบ
- 📧 **สรุปอัตโนมัติรายสัปดาห์** — ส่งเข้าอีเมล (และ LINE ถ้าตั้งค่าไว้) ทุกวันจันทร์ 08:00 น.
- 🚪 **ทะเบียนห้อง + ไทม์ไลน์รายห้อง** — เปิดห้องเดียวเห็นประวัติทั้งหมด: ล้างแอร์ · ซ่อม · ของที่ซื้อเข้าห้อง
- 🧰 **ทะเบียนทรัพย์สินประจำห้อง** — แอร์ / เครื่องทำน้ำอุ่น / ตู้เย็น พร้อมวันติดตั้งและสถานะ
- 📅 **นัดล้างแอร์หลายห้องพร้อมกัน** — เลือกทั้งชั้นหรือทั้งตึกในคลิกเดียว
- 🔎 **ค้นหาข้ามทุกโมดูล** จากช่องเดียวด้านบน
- 📱 **ใช้บนมือถือได้เต็มรูปแบบ** — เพิ่มลงหน้าจอโฮมแล้วใช้เหมือนแอป · รองรับโหมดมืด
- 📝 **บันทึกประวัติการแก้ไข** (ActivityLog) ทุกครั้งที่มีการเพิ่ม/แก้/ลบ

### ระบบผู้ใช้และการตั้งค่า

- 🔐 **ล็อกอินด้วยชื่อผู้ใช้และรหัสผ่าน** — 3 สิทธิ์: ผู้ดูแล / แก้ไขได้ / ดูอย่างเดียว
  แจกให้คนอื่นเข้ามาดูหรือช่วยแก้ได้ ระงับหรือลบทีหลังได้ตลอด
- 🔢 **PIN 6 หลักประจำเครื่อง** — ไม่ต้องพิมพ์รหัสผ่านทุกครั้ง
  ผูกกับเครื่องนั้นเครื่องเดียว ใส่ผิด 5 ครั้งยกเลิกทันที ทำเครื่องหายสั่งยกเลิกทุกเครื่องได้
- ⚙️ **หน้าตั้งค่า 7 หมวด** — ข้อมูลหอพัก · การแสดงผล · การแจ้งเตือน · การเงิน ·
  ความปลอดภัย · การอ่านรูป · การสำรองข้อมูล
- 🌗 **ธีมสว่าง / มืด / ตามเครื่อง** — สลับได้จากปุ่มบนแถบหัว จำแยกรายเครื่อง
- 🔎 **อ่านข้อความจากรูป (OCR)** — แนบสลิปหรือใบเสร็จแล้วระบบเดา
  วันที่ · จำนวนเงิน · ชื่อร้าน · ชื่อรายการ · เลขอ้างอิง ให้ กดเติมแล้วแก้เองได้เสมอ
  รองรับ พ.ศ. เลขไทย และวันที่หลายรูปแบบ
- 🗓️ **ปฏิทินงานที่กำลังจะถึง** — รวมนัดล้างแอร์ · นัดซ่อม · งานตึกที่ครบรอบ ไว้ในหน้าเดียว
- 🏷️ **ค่าใช้จ่ายสะสมรายห้อง** — ห้องไหนกินงบมากที่สุด ใช้ตัดสินใจว่าควรปรับปรุงห้องไหนก่อน
- 💾 **สำรอง/กู้คืนข้อมูล** — ดาวน์โหลดเป็น JSON (นำกลับเข้าระบบได้) หรือ CSV (เปิดใน Excel) และสำรองลง Drive อัตโนมัติทุกวัน
- 🔗 **แชร์ให้คนอื่นดูได้** — ลิงก์แบบดูอย่างเดียว เพิกถอนได้ทุกเมื่อ กันสิทธิ์ที่ฝั่งเซิร์ฟเวอร์
- 🔴 **อัปเดตสด** — ทุกหน้าเช็คว่าชีตเปลี่ยนหรือยังทุก 25 วินาที แล้วโหลดใหม่ให้เอง

## ติดตั้งเวอร์ชัน Google Apps Script (ทำหรือไม่ทำก็ได้)

ถ้าอยากให้ข้อมูลอยู่ใน Google Sheet ของตัวเอง ดูขั้นตอนละเอียดที่ **[docs/DEPLOY.md](docs/DEPLOY.md)** — สรุปสั้น ๆ:

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. คัดลอกไฟล์ใน `src/` ทั้งหมดเข้าโปรเจกต์ (หรือใช้ `clasp push`)
3. รัน `START_HERE()` หนึ่งครั้ง → ระบบสร้างชีต 13 แท็บ + ทะเบียน 24 ห้อง + โฟลเดอร์ Drive + บัญชีผู้ดูแลคนแรก
4. รัน `seedHistoricalData()` เพื่อนำเข้าข้อมูลเดิม
5. **Deploy → New deployment → Web app** → เปิดลิงก์ที่ได้

## ดูตัวอย่างแบบอ่านอย่างเดียว

ไฟล์ [`demo/index.html`](demo/index.html) เปิดในเบราว์เซอร์ได้โดยไม่ต้องต่อเน็ต — ใช้ตอนอยากดูหน้าตาระบบโดยไม่แตะข้อมูลจริง

### เวอร์ชันเว็บแอปทำงานยังไง

โค้ดตรรกะทั้งหมด (`src/*.gs`) ถูกเขียนให้แยกจากชั้นอ่าน/เขียนข้อมูล
`artifact/runtime.js` จึงสลับชั้นนั้นจาก Google Sheet เป็นข้อมูลในหน่วยความจำได้ โดยไม่ต้องแก้ตรรกะแม้แต่บรรทัดเดียว

เวลาบันทึก หน้าเว็บจะประกอบเอกสาร HTML ฉบับใหม่จากแม่แบบของตัวเอง (เก็บเป็น base64 ไว้ในหน้า)
บวกกับข้อมูลล่าสุด แล้วเผยแพร่ทับตัวเอง — ข้อมูลจึงอยู่ในหน้าเว็บนั้นเลย ไม่ต้องมีเซิร์ฟเวอร์

## ทดสอบ

```bash
node test/run.js             # ทดสอบตรรกะฝั่งเซิร์ฟเวอร์ รวมระบบสิทธิ์และล็อกอิน (312 ข้อ)
node build/bundle.js         # รวมซอร์สเป็นไฟล์สำหรับ Apps Script
node build/verify-bundle.js  # เปิดไฟล์ที่รวมแล้วด้วย Chromium จริง (60 ข้อ)
node artifact/build.js       # ประกอบเว็บแอปหน้าเดียว
node artifact/verify.js      # ทดสอบการบันทึกข้าม 3 รุ่น (26 ข้อ)
node test/gen-demo.js        # สร้างหน้าตัวอย่างแบบอ่านอย่างเดียว
```

⚠️ แก้โค้ดที่ `src/` เสมอ แล้วรัน `node build/bundle.js` ใหม่ — อย่าแก้ที่ `build/` โดยตรง
