## 1️⃣ เปิดตัวแก้ไขสคริปต์

เปิด [Google Sheet](https://docs.google.com/spreadsheets/d/1frGWki1sBDG3T4eJxNm5wUZQkXUFcdEIPwKZLaQuSrg/edit)
→ เมนู **ส่วนขยาย (Extensions)** → **Apps Script**

จะเปิดแท็บใหม่ที่มีไฟล์ `Code.gs` และโค้ดตัวอย่างไม่กี่บรรทัด

## 2️⃣ วางโค้ด (ไฟล์เดียว)

1. เปิด **[build/AllInOne.gs](https://github.com/mixmax040137/The-M-Corner-AP/blob/claude/m-corner-ap-system-18u8bz/build/AllInOne.gs)** → กด **Copy raw file** (ไอคอนสองแผ่นซ้อนกัน)
2. กลับมาที่ Apps Script → คลิกในช่องโค้ด → **Ctrl+A / ⌘A** แล้ว **ลบ**
3. **วาง (Ctrl+V / ⌘V)**
4. กด 💾 บันทึก

> ไฟล์ยาวประมาณ 6,400 บรรทัด รอสักครู่ให้โหลดเสร็จก่อนกดบันทึก
> ไม่ต้องสร้างไฟล์อื่นเพิ่ม — หน้าเว็บทั้งหมดฝังอยู่ในไฟล์นี้แล้ว

## 3️⃣ กด Run หนึ่งครั้ง

1. ช่องเลื่อนด้านบน เลือกฟังก์ชัน **`START_HERE`**
2. กด **▶ Run**
3. จะขึ้นขออนุญาต — กดตามนี้:
   **Review permissions → เลือกบัญชีของคุณ → Advanced → Go to The M Corner AP (unsafe) → Allow**

   *(ที่ขึ้นว่า unsafe เพราะเป็นสคริปต์ที่เขียนเอง ยังไม่ได้ส่งให้ Google ตรวจ — ปลอดภัย)*

ฟังก์ชันเดียวนี้ทำให้ครบ:

```
✅ สร้างชีต 13 แท็บ · ทะเบียน 24 ห้อง · โฟลเดอร์ไฟล์แนบ
✅ นำเข้าข้อมูลเดิมครบทุกโมดูล
✅ ออกกุญแจผู้ดูแลและกุญแจแชร์แล้ว
✅ เปิดระบบล็อกอิน · ตั้งค่า · อ่านข้อความจากรูป
✅ สำรองข้อมูลลง Drive อัตโนมัติ ทุกวันตี 2
✅ แจ้งเตือนสรุปงานเข้าอีเมล ทุกวันจันทร์ 08:00
```

พร้อมกับ **ชื่อผู้ใช้และรหัสผ่านของผู้ดูแลคนแรก** — ขึ้นในกล่องข้อความครั้งเดียว **จดไว้ก่อนปิด**

```
👤 บัญชีผู้ดูแลคนแรก (จดไว้ก่อนปิดหน้าต่างนี้)

   ชื่อผู้ใช้  admin
   รหัสผ่าน  xxxxxxxxxxxx
```

> ถ้าเผลอปิดไปก่อนจด ไม่ต้องตกใจ — เมนูในชีต **🏢 The M Corner AP → 🔐 ตั้งรหัสผ่านผู้ดูแลใหม่**
> ออกรหัสใหม่ให้ได้ตลอด

## 4️⃣ กด Deploy

1. มุมขวาบน **Deploy → New deployment**
2. กดเฟือง ⚙️ ข้าง *Select type* → เลือก **Web app**
3. ตั้งค่า:

   | ช่อง | ใส่ว่า |
   |---|---|
   | Execute as | **Me (อีเมลของคุณ)** |
   | Who has access | **Anyone** |

4. **Deploy** → **Done**

## 5️⃣ กด Run อีกครั้งเพื่อรับลิงก์

เลือก **`START_HERE`** แล้วกด **▶ Run** อีกรอบ คราวนี้จะได้ลิงก์ออกมาเลย:

```
🔗 ลิงก์เข้าใช้งาน (ใช้ลิงก์นี้เป็นหลัก — ส่งให้ทุกคนได้)
https://script.google.com/macros/s/.../exec

🆘 ลิงก์กู้ระบบ (ใช้ตอนลืมรหัสผ่านจนเข้าไม่ได้ — ห้ามส่งต่อ)
https://script.google.com/macros/s/.../exec?key=xxxxxxxx

👀 ลิงก์ดูอย่างเดียวแบบไม่ต้องล็อกอิน
https://script.google.com/macros/s/.../exec?key=yyyyyyyy
```

## 6️⃣ เข้าใช้งานครั้งแรก

1. เปิด **ลิงก์เข้าใช้งาน** → จะเจอหน้าล็อกอิน
2. ใส่ `admin` กับรหัสผ่านที่จดไว้จากขั้นตอน 3
3. ระบบให้ตั้งรหัสผ่านของคุณเอง (อย่างน้อย 8 ตัว) — ตั้งแล้วเข้าระบบได้เลย
4. ระบบจะชวน **ตั้ง PIN 6 หลัก** — ตั้งไว้แล้วครั้งต่อไปกดแค่ 6 หลักก็เข้าได้
   ไม่ต้องพิมพ์รหัสผ่านอีก (PIN ผูกกับเครื่องนี้เครื่องเดียว)

**เสร็จแล้ว** 🎉

> รัน `START_HERE` ซ้ำได้ตลอด ไม่ทำข้อมูลซ้ำและไม่ตั้ง trigger ซ้ำ
> หรือจะดูลิงก์จากเมนู **🏢 The M Corner AP → 🔗 แสดงลิงก์เข้าใช้งาน** ในชีตก็ได้ (กด F5 ก่อน)

## ทำไมผมทำ 3 ขั้นตอนหลังให้ไม่ได้

| ขั้นตอน | เหตุผล |
|---|---|
| สร้างโปรเจกต์ Apps Script | ต้องใช้ Apps Script API ซึ่งเจ้าของบัญชีต้องเปิดเองที่ [script.google.com/home/usersettings](https://script.google.com/home/usersettings) และตัวเชื่อม Google Drive ที่ผมมีสร้างได้แค่ Docs / Sheets / Slides / Forms / โฟลเดอร์ (ผมลองแล้ว ระบบปฏิเสธ) |
| กด Allow อนุญาตสิทธิ์ | หน้าจอยินยอมของ Google เป็นการยืนยันตัวตนในเบราว์เซอร์ ออกแบบมาให้ทำแทนกันไม่ได้โดยตั้งใจ |
| กด Deploy | ต้องใช้ Apps Script API เช่นกัน และผูกกับการอนุญาตสิทธิ์ข้างต้น |

ไม่ใช่เรื่องสิทธิ์ที่เปิดให้กันได้ — เป็นกำแพงความปลอดภัยของ Google ที่กันไม่ให้ใครติดตั้งสคริปต์
ในบัญชีคนอื่นได้แม้จะถือ token อยู่ก็ตาม (ถ้าทำได้ ใครแฮ็ก token ไปก็ฝังสคริปต์ในบัญชีเราได้ทันที)

## เรื่องที่ควรรู้

### ข้อมูลอัปเดตยังไง · ตัวบอกสถานะมุมขวาบน

มุมขวาบนมีป้ายบอกตลอดว่าตอนนี้ข้อมูลตรงกับหลังบ้านหรือยัง

| ป้าย | หมายความว่า |
|---|---|
| ● **ซิงก์แล้ว** | ทุกอย่างตรงกับข้อมูลหลังบ้าน (ชี้เมาส์ดูเวลาที่ซิงก์ล่าสุดได้) |
| ⟳ **กำลังบันทึก…** | กำลังส่งข้อมูลขึ้นไปเก็บ |
| ✓ **บันทึกแล้ว** | เก็บเรียบร้อย |
| ⟳ **กำลังซิงก์…** | กำลังดึงข้อมูลล่าสุดลงมาเบื้องหลัง |
| ↻ **มีข้อมูลใหม่** | มีคนแก้จากที่อื่นตอนคุณกำลังกรอกอยู่ · **กดเพื่อโหลดเมื่อพร้อม** |
| ⚠ **เชื่อมต่อไม่ได้** | เน็ตสะดุด · **กดเพื่อลองใหม่** (ของที่กรอกไว้ยังอยู่ในฟอร์ม ไม่หาย) |
| ○ **ไม่ตรวจอัตโนมัติ** | ปิดการตรวจไว้ · กดที่ป้ายเพื่อซิงก์เองได้ |

**หน้าจะไม่ถูกโหลดใหม่ทั้งหน้า** — กดบันทึกแล้วระบบซิงก์เงียบ ๆ เบื้องหลัง
ไม่มีวงกลมหมุนทับหน้า ไม่กระพริบ และไม่เด้งกลับไปบนสุด แถวที่กางดูอยู่ก็ยังกางอยู่เหมือนเดิม

**และจะไม่โหลดทับตอนที่คุณกำลังกรอกข้อมูลอยู่เด็ดขาด** — ถ้ามีข้อมูลใหม่เข้ามาตอนฟอร์มเปิดค้าง
หรือเคอร์เซอร์ยังอยู่ในช่องกรอก ป้ายจะเปลี่ยนเป็น ↻ **มีข้อมูลใหม่** ไว้เฉย ๆ ให้กดเองเมื่อพร้อม

จังหวะการอัปเดตมีสองแบบ
1. **กดบันทึกแล้วซิงก์ทันที** ไม่ต้องรอ
2. **ตรวจการแก้จากที่อื่นทุก 5 นาที** (คนอื่นแก้ หรือคุณไปพิมพ์ในชีตตรง ๆ)

ปรับรอบได้ที่ **⚙️ ตั้งค่า → หน้าตาและการแสดงผล → ตรวจข้อมูลใหม่อัตโนมัติ**
(ปิด / 1 / 5 / 15 / 30 นาที)

### "Anyone" ปลอดภัยไหม
ปลอดภัย — เปิด URL เปล่า ๆ จะเจอ **หน้าล็อกอิน** ไม่เห็นข้อมูลอะไรเลยจนกว่าจะยืนยันตัวตนผ่าน
การกันสิทธิ์ทำที่ฝั่งเซิร์ฟเวอร์ในฟังก์ชัน `api()` ก่อนทำงานทุกครั้ง ไม่ใช่แค่ซ่อนปุ่มในหน้าเว็บ

ที่ต้องเลือก "Anyone" เพราะถ้าเลือก "Anyone with Google account" คนที่คุณแจกชื่อผู้ใช้ให้
จะต้องมีบัญชี Google ถึงจะเปิดได้ — ซึ่งไม่จำเป็น เพราะระบบมีรหัสผ่านของตัวเองอยู่แล้ว

### แจกให้คนอื่นเข้ามาดูหรือช่วยแก้ยังไง
หน้า **⚙️ ตั้งค่า → 👥 ผู้ใช้ในระบบ → + เพิ่มผู้ใช้** ตั้งชื่อผู้ใช้ รหัสผ่านเริ่มต้น และสิทธิ์

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| **ดูอย่างเดียว** | เปิดดูได้ทุกหน้า แก้ไม่ได้ ดาวน์โหลดไฟล์สำรองไม่ได้ |
| **แก้ไขได้** | เพิ่ม แก้ ลบข้อมูลได้ แต่จัดการผู้ใช้และการตั้งค่าไม่ได้ |
| **ผู้ดูแล** | ทำได้ทุกอย่าง รวมถึงจัดการผู้ใช้และการตั้งค่า |

ส่งชื่อผู้ใช้กับรหัสผ่านให้เจ้าตัว แล้วเขาเข้าที่ **ลิงก์เข้าใช้งาน** เดียวกันได้เลย
ระบบจะบังคับให้เขาเปลี่ยนรหัสผ่านตอนเข้าครั้งแรก · ระงับหรือลบทีหลังได้ตลอด

### PIN 6 หลักทำงานยังไง
ตั้งได้ที่ **⚙️ ตั้งค่า → 👤 บัญชีของฉัน → 🔢 ตั้ง PIN สำหรับเครื่องนี้**
PIN ผูกกับ *เครื่องนั้น ๆ* ไม่ใช่กับบัญชี — ตั้งบนมือถือแล้วเปิดบนคอมก็ยังต้องใช้รหัสผ่านอยู่ดี
ใส่ผิด 5 ครั้ง PIN บนเครื่องนั้นถูกยกเลิกทันที ต้องกลับไปใช้รหัสผ่าน
ทำเครื่องหาย → **ยกเลิก PIN ทุกเครื่อง** ในหน้าเดียวกัน

### อ่านข้อความจากรูป (OCR) ทำงานยังไง
แนบสลิปหรือใบเสร็จในฟอร์มไหนก็ได้ → กด **🔎 อ่านข้อความจากรูปนี้**
ระบบเดา วันที่ · จำนวนเงิน · ชื่อร้าน · ชื่อรายการ · เลขอ้างอิง ให้
กดเติมทีละช่องหรือเติมทั้งหมดก็ได้ และ **แก้เองได้เสมอ** — ค่าที่ได้เป็นแค่ข้อเสนอ ตรวจก่อนบันทึกทุกครั้ง

ตั้งให้เติมอัตโนมัติโดยไม่ต้องกดได้ที่ **⚙️ ตั้งค่า → 🔎 อ่านข้อความจากรูป → เมื่ออ่านรูปเสร็จให้ทำอะไร**

### สลับธีมสว่าง/มืด
ปุ่ม 🌗 บนแถบหัว (วนสว่าง → มืด → ตามเครื่อง) หรือเลือกในหน้า **⚙️ ตั้งค่า → 🎨 ธีมสีหน้าจอ**
ธีมจำแยกรายเครื่อง ตั้งบนมือถือกับบนคอมคนละแบบได้

### ลิงก์ดูอย่างเดียวแบบไม่ต้องล็อกอิน
ค่าตั้งต้นคือ **ปิด** — ทุกคนต้องล็อกอิน ถ้าอยากเปิดให้ใครก็ตามที่มีลิงก์เข้าดูได้เลย
ไปที่ **⚙️ ตั้งค่า → 🔐 ความปลอดภัยและการเข้าใช้งาน → เปิดลิงก์แชร์แบบไม่ต้องล็อกอิน** = เปิด

ลิงก์หลุด → เมนูในชีต **🔁 ออกลิงก์แชร์ใหม่** (หรือปุ่มในหน้าตั้งค่า) ลิงก์เดิมใช้ไม่ได้ทันที
ลิงก์กู้ระบบและบัญชีผู้ใช้ไม่ถูกกระทบ

### แก้โค้ดแล้วเว็บไม่เปลี่ยน
**Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
ลิงก์เดิมใช้ได้ต่อ ไม่ต้องแจกใหม่

### แก้ข้อมูลในชีตโดยตรงได้ไหม
ได้เลย ระบบอ่านจากชีตตลอด แค่อย่าลบหรือสลับหัวตารางแถวแรก
ดูว่าใครแก้อะไรได้ที่ชีต `ActivityLog`

| ใส่ PIN ผิดจน PIN ถูกยกเลิก | เข้าด้วยรหัสผ่านตามปกติ แล้วตั้ง PIN ใหม่ในหน้าตั้งค่า |
| อ่านรูปแล้วได้ตัวเลขผิด | แก้ในช่องได้เลย ค่าที่ได้เป็นแค่ข้อเสนอ · รูปเอียงหรือมืดจะอ่านพลาดง่าย ถ่ายใหม่ให้ตรงและสว่างขึ้น |
| กด Run แล้วขึ้น `Script function not found` | ยังบันทึกไม่เสร็จ กด 💾 แล้วเลือกฟังก์ชันใหม่จากช่องเลื่อน |
| ไม่มีเมนู 🏢 ในชีต | โหลดหน้าชีตใหม่ (F5) |
| อัปโหลดรูปแล้วไม่ขึ้น | ไฟล์เกิน 12 MB — ถ่ายด้วยความละเอียดต่ำลง |
| วันที่เพี้ยน | ระบบอ่านได้ทั้ง `26/04/26`, `5/20/2026` และ พ.ศ. `19/01/2565` ถ้ายังเพี้ยนให้กรอกเป็น `YYYY-MM-DD` |

## สำหรับคนที่อยากแก้โค้ดต่อ

`build/AllInOne.gs` เป็นไฟล์ที่ **สร้างอัตโนมัติ** — อย่าแก้ตรงนั้น

```bash
# แก้ที่ src/ แล้วสร้างใหม่
node build/bundle.js         # ได้ AllInOne.gs + Code.gs + Index.html
node test/run.js             # ทดสอบตรรกะ 312 ข้อ
node test/upgrade.js         # ซ้อมอัปเกรดระบบที่มีข้อมูลอยู่แล้ว 35 ข้อ
node build/verify-bundle.js  # ทดสอบไฟล์ที่จะนำไปวางบนเบราว์เซอร์จริง 60 ข้อ
```

ถ้าใช้ [clasp](https://github.com/google/clasp) ได้ จะสะดวกกว่า — ไม่ต้องคัดลอกวางเลย:

```bash
npm install -g @google/clasp
clasp login
clasp clone <scriptId>   # ดู scriptId ที่ Apps Script → Project Settings
cp -r src/* .            # ใช้ไฟล์แยกตามโมดูล อ่านง่ายกว่า
clasp push
```
