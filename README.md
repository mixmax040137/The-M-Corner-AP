# 🏢 The M Corner AP — ระบบบริหารหอพัก

ระบบเดียวที่รวมทุกส่วนของหอพักไว้ด้วยกัน — หนี้สิน · รายการซื้อของ · ล้างแอร์ · ซ่อมแซมรายห้อง · ซ่อมแซมตึก
ทำงานบน **Google Apps Script + Google Sheets + Google Drive** ต่อยอดจากชีตเดิมโดยตรง ไม่มีค่าใช้จ่ายเซิร์ฟเวอร์

---

## สิ่งที่ระบบทำได้

| # | โมดูล | ความสามารถ |
|---|-------|-----------|
| 1 | **รายการสรุปรวม** (หนี้หลัก) | Progress bar ความคืบหน้า · ยอดหนี้ทั้งหมด / ชำระแล้ว / คงเหลือ · แยกตามปี · แนบสลิป · ประมาณการวันปิดหนี้ |
| 2 | **รายการซื้อของ** | วันที่ซื้อ · รายการ · จำนวน · ราคา · แหล่งที่ซื้อ · **ระยะเวลารับประกัน** (คำนวณวันหมดอายุให้) · ภาพประกอบ · สลิปการโอน · แยกตามปี/หมวดหมู่ |
| 3 | **หนี้สิน** (หนี้รอง) | โครงเดียวกับหนี้หลัก แยกบัญชีกัน · แยกเงินต้น / ดอกเบี้ย / ค่าธรรมเนียม |
| 4 | **ซ่อมแซมรายห้อง** | 24 ห้อง แยกเป็น 2 ส่วน — **ล้างแอร์** (หลายรอบต่อปีต่อห้อง) และ **แจ้งซ่อม** (วันนัด · วันเข้าซ่อม · รายการ · ภาพก่อน/หลัง) |
| 5 | **ซ่อมแซมตึกโดยรวม** | งานส่วนกลาง 15 หมวด (ดาดฟ้า · ปั๊มน้ำ · CCTV · ลิฟต์ …) พร้อมรอบบำรุงรักษาถัดไป |

### ส่วนที่เพิ่มให้เพื่อให้ระบบสมบูรณ์

- 📊 **แดชบอร์ดรวม** — ยอดหนี้คงเหลือ · ค่าใช้จ่ายปีนี้ · งานซ่อมค้าง · ห้องที่ยังไม่ล้างแอร์ ในหน้าเดียว
- 🔔 **ศูนย์แจ้งเตือน** — งานซ่อมค้างเกินกำหนด · ห้องถึงรอบล้างแอร์ · ประกันสินค้าใกล้หมดอายุ · งานตึกที่ครบรอบ
- 📧 **สรุปอัตโนมัติรายสัปดาห์** — ส่งเข้าอีเมล (และ LINE ถ้าตั้งค่าไว้) ทุกวันจันทร์ 08:00 น.
- 🚪 **ทะเบียนห้อง + ไทม์ไลน์รายห้อง** — เปิดห้องเดียวเห็นประวัติทั้งหมด: ล้างแอร์ · ซ่อม · ของที่ซื้อเข้าห้อง
- 🧰 **ทะเบียนทรัพย์สินประจำห้อง** — แอร์ / เครื่องทำน้ำอุ่น / ตู้เย็น พร้อมวันติดตั้งและสถานะ
- 📅 **นัดล้างแอร์หลายห้องพร้อมกัน** — เลือกทั้งชั้นหรือทั้งตึกในคลิกเดียว
- 🔎 **ค้นหาข้ามทุกโมดูล** จากช่องเดียวด้านบน
- 📱 **ใช้บนมือถือได้เต็มรูปแบบ** — เพิ่มลงหน้าจอโฮมแล้วใช้เหมือนแอป · รองรับโหมดมืด
- 📝 **บันทึกประวัติการแก้ไข** (ActivityLog) ทุกครั้งที่มีการเพิ่ม/แก้/ลบ

## เริ่มใช้งาน

ดูขั้นตอนแบบละเอียดที่ **[docs/DEPLOY.md](docs/DEPLOY.md)** — สรุปสั้น ๆ:

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. คัดลอกไฟล์ใน `src/` ทั้งหมดเข้าโปรเจกต์ (หรือใช้ `clasp push`)
3. รัน `setupSystem()` หนึ่งครั้ง → ระบบสร้างชีต 10 แท็บ + ทะเบียน 24 ห้อง + โฟลเดอร์ Drive
4. รัน `seedHistoricalData()` เพื่อนำเข้าข้อมูลเดิม
5. **Deploy → New deployment → Web app** → เปิดลิงก์ที่ได้

## ดูตัวอย่างก่อนติดตั้ง

เปิดไฟล์ [`demo/index.html`](demo/index.html) ในเบราว์เซอร์ได้เลย — เป็นหน้าตาระบบจริงพร้อมข้อมูลจริง (โหมดอ่านอย่างเดียว)

## โครงสร้างโปรเจกต์

```
src/
├── appsscript.json      การตั้งค่าโปรเจกต์ + ขอบเขตสิทธิ์
├── Config.gs            ⭐ ค่าคงที่ทั้งหมด: 24 ห้อง, โครงสร้างทุกชีต, ตัวเลือก dropdown
├── Util.gs              อ่าน/เขียนชีต, แปลงวันที่ (รองรับ พ.ศ. และ ค.ศ.), บันทึก log
├── Setup.gs             ติดตั้งระบบ, เมนูในชีต, จัดรูปแบบคอลัมน์
├── Seed.gs              ข้อมูลเดิมจากชีต + ตัวนำเข้า
├── Auth.gs              ควบคุมสิทธิ์เข้าใช้งาน
├── Drive.gs             อัปโหลด/จัดโฟลเดอร์ไฟล์แนบ
├── Debt.gs              หนี้หลัก + หนี้รอง (ใช้ตรรกะร่วมกัน)
├── Purchase.gs          รายการซื้อของ + ติดตามระยะประกัน
├── Maintenance.gs       ล้างแอร์ + ซ่อมรายห้อง + ทะเบียนห้อง + ทรัพย์สิน
├── Building.gs          ซ่อมแซมตึกโดยรวม
├── Dashboard.gs         สรุปภาพรวม + ศูนย์แจ้งเตือน + ค้นหา
├── Api.gs               ⭐ ประตูเดียวที่หน้าเว็บเรียก (38 คำสั่ง)
├── Web.gs               doGet
├── Notify.gs            สรุปอีเมล/LINE + ตั้งเวลาอัตโนมัติ
└── ui/
    ├── Index.html       โครงหน้า
    ├── Style.html       ธีม (สว่าง/มืด) + responsive
    ├── App.html         แกนกลาง: เรียก API, เปลี่ยนหน้า, modal, อัปโหลดไฟล์
    ├── Views.html       ตัววาดของแต่ละหน้า
    └── Forms.html       ฟอร์มเพิ่ม/แก้ไขทุกโมดูล

test/
├── mock-gas.js          ตัวจำลอง Apps Script runtime
├── run.js               ชุดทดสอบ 66 ข้อ (รันด้วย node test/run.js)
└── gen-demo.js          สร้าง demo/index.html จากข้อมูลจริง
```

## ทดสอบ

```bash
node test/run.js      # ทดสอบตรรกะฝั่งเซิร์ฟเวอร์ทั้งหมด (66 ข้อ)
node test/gen-demo.js # สร้างหน้าตัวอย่างใหม่
```
