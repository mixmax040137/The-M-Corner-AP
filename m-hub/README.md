# M Hub — ศูนย์รวมเครื่องมือทำงาน

**เปิดใช้งาน:** https://m-hub.mcorner-ap.workers.dev

เว็บแอปที่รวมงานซ้ำ ๆ ไว้ในที่เดียว ทำงานบนเครื่องของผู้ใช้ทั้งหมด (ไฟล์ไม่ถูกอัปโหลดไปไหน) ติดตั้งเป็นโปรแกรมได้ ใช้ออฟไลน์ได้หลังเปิดครั้งแรก และออกแบบให้เพิ่มเครื่องมือใหม่ได้เรื่อย ๆ

เป็น Cloudflare Worker ตัวใหม่ชื่อ `m-hub` ในบัญชีส่วนตัว **แยกจากระบบเดิมทั้งหมด** (`m-corner-ap`, `moneyflow`, `design` ไม่ถูกแตะ) โค้ดทั้งหมดอยู่ในโฟลเดอร์นี้

## เครื่องมือที่มี

| เครื่องมือ | ทำอะไรได้ |
|---|---|
| **จัดการรูปเป็นชุด** | ย่อขนาด (ด้านยาว / กว้าง / สูง / พอดีกรอบ / ครอป / %), แปลงเป็น JPG · PNG · WebP · AVIF, รับไฟล์ HEIC จาก iPhone, เปลี่ยนชื่อตามรูปแบบหรือตามรายชื่อใน Excel (เรียงลำดับ หรือจับคู่ตามชื่อไฟล์เดิม), จัดเข้าโฟลเดอร์ตามวันที่ถ่าย / คอลัมน์ Excel, ใส่โลโก้ลายน้ำ, คัดลอกหรือ**ย้าย**ไฟล์ (จัดคลังรูป), พรีเซ็ตสำเร็จรูป + บันทึกพรีเซ็ตเอง |
| **ออกเอกสารจากเทมเพลต** | รายชื่อจาก Excel/CSV/วางจาก Excel + “ข้อมูลกลาง” (ชื่องาน วันที่ สถานที่) → **อีเมลเป็นชุด** (ฉบับร่าง .eml เปิดใน Outlook กดส่งได้เลย พร้อมไฟล์แนบรายคน, ลิงก์ Gmail/Outlook เว็บ, CSV), **เกียรติบัตร / ป้ายชื่อ / ป้ายห้อยคอ / จดหมาย PDF** (ใส่พื้นหลังจาก Canva เป็น PNG/PDF, ลากวางตำแหน่ง, ฟอนต์ไทย 5 แบบ + เพิ่มฟอนต์เองเช่น TH SarabunPSK, ป้ายชื่อหลายใบต่อ A4 พร้อมเส้นตัด), **Word รายคน** (ใช้ไฟล์ .docx ของเราเองที่มี `{{ชื่อคอลัมน์}}`) |
| **ร่างอีเมลประกาศ ไทย/อังกฤษ** | อ่าน PDF ประกาศทั้งโฟลเดอร์ ดึงเรื่อง เลขที่ วันประกาศ วันสำคัญ อีเมล เบอร์โทร ลิงก์ ผู้ลงนาม → ร่างอีเมลไทย + อังกฤษ (แปลชื่อหน่วยงานด้วยคลังคำ วันที่ พ.ศ. → ค.ศ. อัตโนมัติ) → ปุ่ม “แปลด้วย AI ฟรี” (Workers AI) หรือ “คัดลอกข้อมูลย่อสำหรับ AI” (ใช้ token น้อยกว่าส่งทั้งไฟล์มาก) → ฉบับร่าง .eml แนบ PDF ให้แล้ว |
| **รวม / แยก / แปลง PDF** | รวมหลายไฟล์ (เลือกหน้าได้), แยกทุกหน้า / ตามช่วง / ดึงเฉพาะหน้า, หมุนหน้า, รวมรูปเป็น PDF, แปลง PDF เป็นรูป |

### จุดที่ควรรู้
- **เชื่อมโฟลเดอร์ในเครื่องโดยตรง** ใช้ได้บน Chrome / Edge บนคอมพิวเตอร์ (เบราว์เซอร์อื่นยังใช้ได้ทุกเครื่องมือ โดยรับผลเป็น ZIP)
- **บันทึกลงโฟลเดอร์ไม่เขียนทับไฟล์เดิม** ชื่อซ้ำจะต่อท้าย (2), (3)
- **HEIC:** รับเป็นไฟล์ต้นทางได้ แต่ไม่มีเบราว์เซอร์ใดสร้างไฟล์ .HEIC ได้ จึงใช้ **AVIF** (ตระกูล HEIF เดียวกัน ไฟล์เล็กกว่า) แทน
- **PDF ที่เป็นภาพสแกน** ไม่มีข้อความให้ดึง ระบบจะเตือนและให้กรอกเอง
- **PDF จาก Chrome / Google Docs** มักทำวรรณยุกต์ไทยหาย ระบบซ่อมให้อัตโนมัติด้วยพจนานุกรมไทยในเบราว์เซอร์ (ไม่ใช้ AI) — ควรตรวจทานทุกครั้ง
- **ข้อความที่แปลด้วย AI ต้องตรวจทานก่อนส่งเสมอ** (ใช้โควตาฟรีของ Workers AI ในบัญชี และรับเฉพาะคำขอจากหน้าเว็บ M Hub เอง)
- ค่าตั้ง พรีเซ็ต และฟอนต์ที่เพิ่ม จำไว้ในเบราว์เซอร์ของเครื่องนั้น

## ติดตั้งเป็นโปรแกรม
เปิดเว็บใน Chrome / Edge → กดปุ่ม **ติดตั้งลงเครื่อง** มุมขวาบน (หรือไอคอน ⊕ ในช่องที่อยู่เว็บ) · บน iPhone/iPad: ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”

## โครงสร้าง
```
m-hub/
├─ wrangler.jsonc          ตั้งค่า Worker (บัญชีส่วนตัว, ชื่อ m-hub, Workers AI)
├─ src/worker.js           เสิร์ฟหน้าเว็บ + /api/health + /api/translate + /cdn/avif/*
├─ public/                 ตัวแอปทั้งหมด (HTML/CSS/JS ธรรมดา ไม่ต้อง build)
│  ├─ app.js               โครงหลัก เมนู เปลี่ยนหน้า โฟลเดอร์ทำงาน ติดตั้ง
│  ├─ core/                ส่วนกลางที่ทุกเครื่องมือใช้ร่วมกัน
│  │  ├─ ui.js             ปุ่ม ช่องกรอก แท็บ พรีเซ็ต แจ้งเตือน เติม {{ตัวแทน}}
│  │  ├─ workspace.js      เชื่อม/อ่าน/เขียนโฟลเดอร์ในเครื่อง
│  │  ├─ output.js         บันทึกผลลงโฟลเดอร์ หรือ ZIP
│  │  ├─ data.js           อ่าน Excel / CSV / วางจาก Excel
│  │  ├─ image.js          ถอด/ย่อ/เข้ารหัสรูป, ลายน้ำ, EXIF
│  │  ├─ pdf.js            อ่าน/สร้าง PDF, ดึงข้อความ
│  │  ├─ eml.js            สร้างอีเมล .eml, ลิงก์ Gmail/Outlook
│  │  └─ thai.js           วันที่ไทย↔อังกฤษ, ตัดคำ, ซ่อมวรรณยุกต์
│  ├─ tools/               เครื่องมือ 1 ไฟล์ต่อ 1 ตัว + registry.js
│  └─ sw.js, manifest      ใช้ออฟไลน์ + ติดตั้งเป็นแอป
├─ scripts/vendor.mjs      คัดลอกไลบรารีจาก node_modules → public/vendor
├─ scripts/embed.mjs       ฝัง public/ ลงสคริปต์ Worker (src/assets.gen.js)
└─ test/                   e2e.mjs (ทดสอบทุกเครื่องมือในเบราว์เซอร์), live.mjs (ทดสอบเว็บจริง)
```

## เพิ่มเครื่องมือใหม่
1. สร้างไฟล์ `public/tools/<ชื่อ>.js`
   ```js
   import { h, btn, step, toast } from '../core/ui.js';
   export function mount(root) {
     root.append(step(1, 'ขั้นแรก', btn('ทำงาน', () => toast('สวัสดี'), { kind: 'primary' })));
   }
   ```
2. เพิ่ม 1 รายการใน `public/tools/registry.js` (id, ชื่อ, ไอคอน, คำอธิบาย, `load: () => import('./<ชื่อ>.js')`)
3. ทดสอบในเครื่อง แล้ว deploy (ด้านล่าง)

หรือบอก Claude ว่าอยากได้เครื่องมืออะไร — ไอเดียที่รออยู่แสดงในหน้าแรก (OCR ไทย, QR Code เป็นชุด, ภาพปกโพสต์หลายขนาด, ทำความสะอาดรายชื่อ Excel, คลังคำแปลกลาง, ย่อวิดีโอ)

## พัฒนาและ deploy
```bash
cd m-hub
npm install
node test/server.mjs        # เปิด http://127.0.0.1:8788 (ต้องรัน npm run vendor ก่อนครั้งแรก)
npm test                    # ทดสอบทุกเครื่องมือในเบราว์เซอร์ (Playwright)
npm run deploy              # vendor → embed → wrangler deploy ไปบัญชีส่วนตัว
node test/live.mjs          # ทดสอบเว็บจริงหลัง deploy
```
หมายเหตุ: หน้าเว็บถูกฝังในสคริปต์ Worker (ไม่ใช้ Workers Static Assets) ขนาดหลังบีบอัด ~1.9 MB จากเพดานแผนฟรี 3 MB — ตัวเข้ารหัส AVIF (3.5 MB) จึงให้ Worker ดึงจาก jsDelivr แทน และโหลดเฉพาะเมื่อเลือก AVIF
