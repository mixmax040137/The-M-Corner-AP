## วิธีที่ 1 — คัดลอกไฟล์เอง (ง่ายที่สุด ไม่ต้องลงโปรแกรม)

### 1. สร้างชีตใหม่และเปิด Apps Script

1. ไปที่ [sheets.new](https://sheets.new) สร้างชีตเปล่า ตั้งชื่อว่า **`The M Corner AP - ฐานข้อมูล`**
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. จะได้โปรเจกต์เปล่าที่มีไฟล์ `Code.gs` — ลบโค้ดในไฟล์นั้นทิ้งให้หมด

### 2. เปิดใช้ไฟล์ manifest

1. กดรูปเฟือง ⚙️ **Project Settings** ทางซ้าย
2. ติ๊ก ☑️ **Show "appsscript.json" manifest file in editor**
3. กลับไปหน้า **Editor** จะเห็นไฟล์ `appsscript.json`
4. เปิดไฟล์นั้น แล้ววางเนื้อหาจาก `src/appsscript.json` ทับลงไป

### 3. คัดลอกไฟล์โค้ด

สร้างไฟล์ตามรายการนี้ (กด **+ → Script** สำหรับ `.gs`, **+ → HTML** สำหรับ `.html`)

| ตั้งชื่อไฟล์ใน Apps Script ว่า | เอาเนื้อหามาจาก |
|---|---|

> (Apps Script ยอมให้ใช้ `/` ในชื่อไฟล์ได้ตามปกติ)

### 4. รันการติดตั้ง

1. กด 💾 บันทึกทั้งโปรเจกต์
2. เลือกฟังก์ชัน **`setupSystem`** จาก dropdown ด้านบน แล้วกด **▶ Run**
3. ครั้งแรกจะขึ้นขออนุญาต → **Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe) → Allow**
   (ขึ้นว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ส่งให้ Google ตรวจ — ปลอดภัย)
4. เสร็จแล้วกลับไปดูที่ชีต จะมีแท็บใหม่ 10 แท็บ และเมนู **🏢 The M Corner AP** ด้านบน

### 5. นำเข้าข้อมูลเดิม

เลือกฟังก์ชัน **`seedHistoricalData`** แล้วกด **▶ Run**
(หรือใช้เมนูในชีต: **🏢 The M Corner AP → 🌱 นำเข้าข้อมูลเดิม**)

จะได้ข้อความยืนยัน:

```
• ก้อนหนี้: 4 รายการ
• รายการโอนใช้หนี้: 40 รายการ
• รายการซื้อของ: 94 รายการ
• ล้างแอร์: 41 ครั้ง
• ซ่อมแซมตามห้อง: 42 รายการ
• ซ่อมแซมตึกโดยรวม: 4 รายการ
• ทรัพย์สินประจำห้อง: 72 รายการ
```

> รันซ้ำไม่ได้โดยตั้งใจ (กันข้อมูลซ้ำ) — ถ้าอยากรันใหม่ให้เรียก `resetSeedFlag()` ก่อน

### 6. Deploy เป็นเว็บแอป

1. กด **Deploy → New deployment**
2. ไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Description**: `The M Corner AP v1`
   - **Execute as**: `Me (อีเมลคุณ)`
   - **Who has access**: `Only myself` ← เริ่มต้นแบบนี้ก่อน ปลอดภัยที่สุด
4. กด **Deploy** → คัดลอก **Web app URL**
5. เปิด URL นั้นในเบราว์เซอร์ — ระบบพร้อมใช้งาน 🎉

## วิธีที่ 2 — ใช้ clasp (สำหรับอัปเดตโค้ดบ่อย ๆ)

```bash
npm install -g @google/clasp
clasp login

# สร้างโปรเจกต์ใหม่ผูกกับชีต
clasp create --type sheets --title "The M Corner AP" --rootDir src

# หรือผูกกับโปรเจกต์ที่มีอยู่แล้ว
cp .clasp.json.example .clasp.json
# แก้ scriptId ในไฟล์ให้ตรงกับโปรเจกต์ (ดูได้จาก Project Settings ใน Apps Script)

clasp push
clasp open
```

จากนั้นทำต่อจาก **ขั้นตอนที่ 4** ด้านบน

## ตั้งค่าเพิ่มเติม (ทำหรือไม่ทำก็ได้)

ทั้งหมดตั้งใน Apps Script → ⚙️ **Project Settings → Script Properties → Add script property**

| Property | ใส่อะไร | ใช้ทำอะไร |
|---|---|---|
| `ALLOWED_EMAILS` | `mae@gmail.com,chang@gmail.com` | ให้คนอื่นเข้าใช้ระบบได้ (ต้องเปลี่ยน "Who has access" เป็น *Anyone with Google account* ด้วย) |
| `NOTIFY_EMAIL` | อีเมลที่จะรับสรุป | ถ้าไม่ตั้ง จะส่งไปที่เจ้าของชีต |
| `LINE_TOKEN` + `LINE_TO` | token และ userId จาก LINE Messaging API | ส่งสรุปเข้า LINE ด้วย |

### เปิดการแจ้งเตือนอัตโนมัติ

เมนูในชีต **🏢 The M Corner AP → ⏰ ตั้งแจ้งเตือนอัตโนมัติรายสัปดาห์**
→ ระบบจะส่งสรุปงานค้างเข้าอีเมลทุกวันจันทร์ 08:00 น.

### ค่าที่ปรับได้ในชีต `Settings`

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ac_cycle_months` | 6 | ล้างแอร์ทุกกี่เดือน (ใช้คำนวณห้องที่ถึงกำหนด) |
| `warranty_alert_days` | 30 | เตือนก่อนประกันหมดกี่วัน |
| `overdue_alert_days` | 7 | งานซ่อมค้างเกินกี่วันถือว่าเลยกำหนด |
| `door_code` / `admin_code` | (ว่าง) | รหัสเข้าตึก — **กรอกในชีตเท่านั้น อย่าใส่ในโค้ด** |

## ใช้บนมือถือให้เหมือนแอป

1. เปิด Web app URL บนมือถือ
2. **iPhone**: Safari → ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
   **Android**: Chrome → เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก*
3. จะได้ไอคอนเปิดระบบได้ทันที ถ่ายรูปแนบจากกล้องได้เลย

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าเว็บขึ้น "เชื่อมต่อระบบไม่สำเร็จ" | ยังไม่ได้รัน `setupSystem()` หรืออีเมลที่ล็อกอินไม่มีสิทธิ์ (ดู `ALLOWED_EMAILS`) |
