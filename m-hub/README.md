# M Hub — ศูนย์รวมเครื่องมือทำงาน

**เปิดใช้งาน:** https://m-hub.mcorner-ap.workers.dev

เว็บแอปที่รวมงานซ้ำ ๆ ไว้ในที่เดียว ทำงานบนเครื่องของผู้ใช้ทั้งหมด (ไฟล์ไม่ถูกอัปโหลดไปไหน) ติดตั้งเป็นโปรแกรมได้ ใช้ออฟไลน์ได้หลังเปิดครั้งแรก และออกแบบให้เพิ่มเครื่องมือใหม่ได้เรื่อย ๆ

เป็น Cloudflare Worker ตัวใหม่ชื่อ `m-hub` ในบัญชีส่วนตัว **แยกจากระบบเดิมทั้งหมด** (`m-corner-ap`, `moneyflow`, `design` ไม่ถูกแตะ) โค้ดทั้งหมดอยู่ในโฟลเดอร์นี้

## เครื่องมือที่มี

| เครื่องมือ | ทำอะไรได้ |
|---|---|
| **จัดการรูปเป็นชุด** | ย่อขนาด แปลงเป็น JPG · PNG · WebP · AVIF, รับ HEIC, **ครอปตามสัดส่วน** (1:1, 4:5, 16:9, 9:16, A4 ฯลฯ เลือกเก็บกึ่งกลาง/บน/ล่าง/ซ้าย/ขวา), **หมุน 90°/180° และกลับด้านทุกรูป**, เปลี่ยนชื่อตามรูปแบบ/Excel, จัดโฟลเดอร์ตามวันที่ถ่าย/คอลัมน์, ใส่โลโก้, คัดลอกหรือ**ย้าย**ไฟล์ · **ปรับแต่งภาพแบบ Canva ทุกรูปพร้อมกัน**: อุณหภูมิสี โทนสี ความสว่าง คอนทราสต์ ไฮไลต์ เงา ส่วนขาว/ดำ ความสด ความอิ่มสี สลับสี แก้สีรายเฉด (8 สี) ความคม ความชัดเฉพาะจุด ขอบภาพ + ปรับอัตโนมัติ + 11 ฟิลเตอร์ + ใช้เฉพาะบุคคล/พื้นหลัง · **เครื่องมือเสริมเป็นชุด**: ขยายภาพด้วย AI 2×/4×, ลบพื้นหลัง/เปลี่ยนสีพื้น/เบลอพื้นหลัง, รีทัชผิว, เบลอ · **แก้ทีละรูป (ปุ่ม “แก้ไข”)**: ครอปและหมุน (ลากกรอบ/มุมกรอบ ล็อกสัดส่วน หมุนซ้าย-ขวา 90° กลับด้าน ปรับเอียง ±45° แบบไม่มีมุมว่าง), ยางลบวิเศษ (ในเครื่อง/AI), เบลอเฉพาะจุด, แก้ด้วยคำสั่ง, สร้างพื้นหลังใหม่, ขยายขอบภาพ, หยิบบุคคล/แยกเลเยอร์, ดึงข้อความเป็นเลเยอร์ที่แก้ได้, ปรับแต่งเฉพาะพื้นที่ที่ระบาย, เลิกทำ/ทำซ้ำ, กดค้างดูก่อนแก้ |
| **ออกเอกสารจากเทมเพลต** | รายชื่อจาก Excel/CSV/วางจาก Excel + “ข้อมูลกลาง” (ชื่องาน วันที่ สถานที่) → **อีเมลเป็นชุด** (ฉบับร่าง .eml เปิดใน Outlook กดส่งได้เลย พร้อมไฟล์แนบรายคน, ลิงก์ Gmail/Outlook เว็บ, CSV), **เกียรติบัตร / ป้ายชื่อ / ป้ายห้อยคอ / จดหมาย PDF** (ใส่พื้นหลังจาก Canva เป็น PNG/PDF, ลากวางตำแหน่ง, ฟอนต์ไทย 5 แบบ + เพิ่มฟอนต์เองเช่น TH SarabunPSK, ป้ายชื่อหลายใบต่อ A4 พร้อมเส้นตัด), **Word รายคน** (ใช้ไฟล์ .docx ของเราเองที่มี `{{ชื่อคอลัมน์}}`) |
| **ร่างอีเมลประกาศ ไทย/อังกฤษ** | อ่าน PDF ประกาศทั้งโฟลเดอร์ ดึงเรื่อง เลขที่ วันประกาศ วันสำคัญ อีเมล เบอร์โทร ลิงก์ ผู้ลงนาม → ร่างอีเมลไทย + อังกฤษ (แปลชื่อหน่วยงานด้วยคลังคำ วันที่ พ.ศ. → ค.ศ. อัตโนมัติ) → ปุ่ม “แปลด้วย AI ฟรี” (Workers AI) หรือ “คัดลอกข้อมูลย่อสำหรับ AI” (ใช้ token น้อยกว่าส่งทั้งไฟล์มาก) → ฉบับร่าง .eml แนบ PDF ให้แล้ว |
| **รวม / แยก / แปลง PDF** | รวมหลายไฟล์ (เลือกหน้าได้), แยกทุกหน้า / ตามช่วง / ดึงเฉพาะหน้า, หมุนหน้า, รวมรูปเป็น PDF, แปลง PDF เป็นรูป |
| **ภาพปกโพสต์หลายขนาด** | ออกแบบครั้งเดียว ได้ภาพ Facebook, โพสต์สี่เหลี่ยม, IG 4:5, Story, X, แบนเนอร์เว็บ, ปก YouTube (3 รูปแบบ: ภาพเต็ม+ข้อความล่าง / แถบสี / ข้อความกลาง), ใส่โลโก้, ปรับจุดโฟกัสภาพ, ทำหลายโพสต์จาก Excel (จับคู่ภาพตามชื่อไฟล์) |
| **QR Code เป็นชุด** | จากรายชื่อ Excel หรือพิมพ์ทีละบรรทัด รองรับภาษาไทย (UTF-8), ใส่โลโก้กลาง QR, ข้อความใต้ QR, ส่งออก PNG / SVG / แผ่น A4 พร้อมพิมพ์ · ใส่ QR รายคนในเกียรติบัตร/ป้ายชื่อได้ (ปุ่ม “เพิ่ม QR”) |
| **รวม / ทำความสะอาดรายชื่อ** | รวมหลายไฟล์ (หาแถวหัวตารางให้เอง), ตัดช่องว่าง/อักขระแปลก, เลขไทย→อารบิก, แยกคำนำหน้า–ชื่อ–นามสกุล (ผศ.ดร., นางสาว, Assoc. Prof. ฯลฯ), เบอร์โทร 081-234-5678 (+66 → 0), อีเมลตัวเล็ก + ตรวจรูปแบบ, ลบชื่อซ้ำโดยเติมช่องว่างจากแถวซ้ำ → Excel / CSV / ส่งต่อไปออกเอกสารในคลิกเดียว |
| **อ่านข้อความจากภาพ (OCR ไทย)** | ภาพถ่ายเอกสาร ภาพหน้าจอ (กด Ctrl+V วางได้) และ PDF สแกน, ไทย + อังกฤษ, คัดลอก / .txt, ส่งไปร่างอีเมลประกาศได้ · ในเครื่องมือร่างอีเมลประกาศ PDF ที่เป็นภาพสแกนมีปุ่ม “อ่านด้วย OCR” |
| **ย่อ / ตัดวิดีโอ** | เป้าหมายสำเร็จรูป (ส่ง LINE / โซเชียล / คุณภาพสูง) หรือกำหนดขนาดไฟล์ (MB), ตัดช่วงด้วยปุ่ม “ใช้ตำแหน่งที่เล่นอยู่”, ลดความละเอียด, ปิดเสียง, MP4 (H.264) หรือ WebM, บันทึกภาพนิ่งจากวิดีโอ |
| **คลังคำแปลประจำหน่วยงาน** | ตารางคำ ไทย ↔ อังกฤษ แยกหมวด (หน่วยงาน/ตำแหน่ง/สาขา/คำทั่วไป) ค้นหา/แก้/นำเข้า/ส่งออก Excel, ช่องแปลข้อความด้วยคลังคำ (ไม่ใช้ AI) หรือ AI ฟรี — เครื่องมือร่างอีเมลประกาศใช้คลังนี้ร่วมกัน |

### จุดที่ควรรู้
- **เชื่อมโฟลเดอร์ในเครื่องโดยตรง** ใช้ได้บน Chrome / Edge บนคอมพิวเตอร์ (เบราว์เซอร์อื่นยังใช้ได้ทุกเครื่องมือ โดยรับผลเป็น ZIP)
- **บันทึกลงโฟลเดอร์ไม่เขียนทับไฟล์เดิม** ชื่อซ้ำจะต่อท้าย (2), (3)
- **HEIC:** รับเป็นไฟล์ต้นทางได้ แต่ไม่มีเบราว์เซอร์ใดสร้างไฟล์ .HEIC ได้ จึงใช้ **AVIF** (ตระกูล HEIF เดียวกัน ไฟล์เล็กกว่า) แทน
- **PDF ที่เป็นภาพสแกน** ไม่มีข้อความให้ดึง ระบบจะเตือนและให้กรอกเอง
- **PDF จาก Chrome / Google Docs** มักทำวรรณยุกต์ไทยหาย ระบบซ่อมให้อัตโนมัติด้วยพจนานุกรมไทยในเบราว์เซอร์ (ไม่ใช้ AI) — ควรตรวจทานทุกครั้ง
- **ข้อความที่แปลด้วย AI ต้องตรวจทานก่อนส่งเสมอ** (ใช้โควตาฟรีของ Workers AI ในบัญชี และรับเฉพาะคำขอจากหน้าเว็บ M Hub เอง)
- **OCR** ครั้งแรกต้องโหลดตัวอ่าน + ข้อมูลภาษาไทยประมาณ 5 MB (เบราว์เซอร์จำไว้ ครั้งต่อไปเร็วและใช้ออฟไลน์ได้) · ภาพชัด ตรง ตัวหนังสือใหญ่ จะอ่านแม่นที่สุด
- **วิดีโอ** ใช้ WebCodecs ของเบราว์เซอร์ (Chrome / Edge แนะนำ) · ถ้าเบราว์เซอร์สร้างเสียง AAC ไม่ได้ ระบบจะเตือนว่าไฟล์ MP4 ใช้เสียง Opus (บาง iPhone อาจไม่มีเสียง)
- **QR** ทดสอบสแกนด้วยตัวอ่าน QR อัตโนมัติแล้ว รวมถึงข้อความภาษาไทย
- **เครื่องมือภาพแบบ Canva**
  - *ในเครื่อง (ไม่ต้องใช้เน็ตหลังโหลดครั้งแรก)*: ปรับแต่ง/ฟิลเตอร์, ยางลบวิเศษแบบในเครื่อง, เบลอ, รีทัชผิว, ลบ/เบลอพื้นหลัง, หยิบบุคคล, ดึงข้อความ, ขยายภาพด้วย AI — ใช้ TensorFlow.js กับโมเดล Robust Video Matting (แยกบุคคล ~4 MB) และ ESRGAN (ขยายภาพ ~1 MB) โหลดผ่าน `/cdn/` ครั้งแรกแล้วเบราว์เซอร์จำไว้
  - การแยกพื้นหลัง/หยิบวัตถุ **รองรับบุคคลเป็นหลัก** (โมเดลทั่วไปสำหรับสิ่งของใหญ่และหนักเกินกว่าจะโหลดในเบราว์เซอร์)
  - *AI สร้างภาพ (ใช้เน็ต)*: แก้ด้วยคำสั่ง, ยางลบแบบ AI, สร้างพื้นหลังใหม่, ขยายขอบภาพ, เติมพื้นหลังตอนหยิบบุคคล — ใช้ FLUX.2 [klein] 4B ผ่าน Workers AI ของบัญชีนี้ (โควตาฟรี 10,000 neurons/วัน ใช้ร่วมกับการแปล — ประมาณ 30–40 ครั้งต่อวันสำหรับเครื่องมือ AI ภาพ, รีเซ็ต 07:00 น. เวลาไทย; เมื่อหมดจะขึ้นข้อความแจ้ง เครื่องมือที่ไม่ใช้ AI ยังใช้ได้ปกติ) ส่งภาพไป Cloudflare **เฉพาะตอนกดใช้เครื่องมือ AI** · ผลแต่ละครั้งไม่เหมือนกัน ไม่ถูกใจกด Ctrl+Z แล้วลองใหม่ · คำสั่งภาษาไทยจะแปลเป็นอังกฤษก่อนส่ง
  - หน้าต่างแก้ไขทีละรูปทำงานที่ด้านยาวไม่เกิน 2400 px (ขยายภาพด้วย AI ได้ถึง 6000 px)
- ค่าตั้ง พรีเซ็ต และฟอนต์ที่เพิ่ม จำไว้ในเบราว์เซอร์ของเครื่องนั้น

## ติดตั้งเป็นโปรแกรม
เปิดเว็บใน Chrome / Edge → กดปุ่ม **ติดตั้งลงเครื่อง** มุมขวาบน (หรือไอคอน ⊕ ในช่องที่อยู่เว็บ) · บน iPhone/iPad: ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”

## โครงสร้าง
```
m-hub/
├─ wrangler.jsonc          ตั้งค่า Worker (บัญชีส่วนตัว, ชื่อ m-hub, Workers AI)
├─ src/worker.js           เสิร์ฟหน้าเว็บ + /api/health + /api/translate + /cdn/avif/*
├─ public/                 ตัวแอปทั้งหมด (HTML/CSS/JS ธรรมดา ไม่ต้อง build)
│  ├─ app.js               โครงหลัก เมนู เปลี่ยนหน้า โฟลเดอร์ทำงาน ติดตั้ง
│  ├─ core/                ส่วนกลางที่ทุกเครื่องมือใช้ร่วมกัน
│  │  ├─ ui.js             ปุ่ม ช่องกรอก แท็บ พรีเซ็ต แจ้งเตือน เติม {{ตัวแทน}}
│  │  ├─ workspace.js      เชื่อม/อ่าน/เขียนโฟลเดอร์ในเครื่อง
│  │  ├─ output.js         บันทึกผลลงโฟลเดอร์ หรือ ZIP
│  │  ├─ data.js           อ่าน Excel / CSV / วางจาก Excel
│  │  ├─ image.js          ถอด/ย่อ/เข้ารหัสรูป, ลายน้ำ, EXIF
│  │  ├─ pdf.js            อ่าน/สร้าง PDF, ดึงข้อความ
│  │  ├─ eml.js            สร้างอีเมล .eml, ลิงก์ Gmail/Outlook
│  │  ├─ thai.js           วันที่ไทย↔อังกฤษ, ตัดคำ/ตัดบรรทัด, ซ่อมวรรณยุกต์
│  │  ├─ glossary.js       คลังคำแปลกลาง + แปลด้วย Workers AI
│  │  ├─ qr.js             สร้าง QR (UTF-8)
│  │  ├─ ocr.js            OCR ด้วย Tesseract
│  │  ├─ bus.js            ส่งข้อมูลระหว่างเครื่องมือ (เช่น รายชื่อ → ออกเอกสาร)
│  │  ├─ adjust.js         ปรับแสง/สี/พื้นผิว, ปรับอัตโนมัติ, ฟิลเตอร์
│  │  ├─ fx.js             เบลอ, เบลอพื้นหลัง, รีทัชผิว, เปลี่ยนพื้นหลัง, ลบวัตถุ (PatchMatch)
│  │  ├─ ml.js             TensorFlow.js: แยกบุคคล (RVM), ขยายภาพ (ESRGAN)
│  │  └─ genai.js          แก้ภาพด้วย FLUX.2 ผ่าน Workers AI
│  ├─ tools/               เครื่องมือ 1 ไฟล์ต่อ 1 ตัว + registry.js
│  └─ sw.js, manifest      ใช้ออฟไลน์ + ติดตั้งเป็นแอป
├─ scripts/vendor.mjs      คัดลอกไลบรารีจาก node_modules → public/vendor
├─ scripts/embed.mjs       ฝัง public/ ลงสคริปต์ Worker (src/assets.gen.js)
└─ test/                   e2e.mjs (ทดสอบทุกเครื่องมือในเบราว์เซอร์), live.mjs (ทดสอบเว็บจริง)
```

## เพิ่มเครื่องมือใหม่
1. สร้างไฟล์ `public/tools/<ชื่อ>.js`
   ```js
   import { h, btn, step, toast } from '../core/ui.js';
   export function mount(root) {
     root.append(step(1, 'ขั้นแรก', btn('ทำงาน', () => toast('สวัสดี'), { kind: 'primary' })));
   }
   ```
2. เพิ่ม 1 รายการใน `public/tools/registry.js` (id, ชื่อ, ไอคอน, คำอธิบาย, `load: () => import('./<ชื่อ>.js')`)
3. ทดสอบในเครื่อง แล้ว deploy (ด้านล่าง)

หรือบอก Claude ว่าอยากได้เครื่องมืออะไร — ไอเดียถัดไปแสดงในหน้าแรก (ตัดพื้นหลังรูป, รายงานสรุปกิจกรรม, ปฏิทินโพสต์, ลายเซ็นอีเมลหน่วยงาน)

## พัฒนาและ deploy
```bash
cd m-hub
npm install
node test/server.mjs        # เปิด http://127.0.0.1:8788 (ต้องรัน npm run vendor ก่อนครั้งแรก)
npm test                    # ทดสอบทุกเครื่องมือในเบราว์เซอร์ (Playwright) — ดึงไฟล์โมเดลสำหรับเทสต์ไว้ที่ test/cache/ ให้อัตโนมัติ
npm run deploy              # vendor → embed → wrangler deploy ไปบัญชีส่วนตัว
node test/live.mjs          # ทดสอบเว็บจริงหลัง deploy
```
